# PHI_E_BIKE — Assembly Steps

> **Skill Level**: Beginner (12-year-old can do it with adult supervision)
> **Time**: 4-6 hours over a weekend
> **Tools Needed**: Allen keys, wrenches, screwdrivers, wire strippers, multimeter

---

## Phase 1: Prepare the Bicycle (1 hour)

### Step 1: Inspect the Base Bike

1. Get a used 26" mountain bike in good condition
2. Check all bolts are tight
3. Check tires hold air
4. Check brakes work
5. Check chain moves freely
6. Check wheels spin true (no wobble)
7. **Do NOT proceed if bike needs major repairs**

### Step 2: Remove Rear Wheel

1. Flip bike upside down (rest on handlebars and seat)
2. Release brake caliper (open the quick-release lever on caliper)
3. Open rear wheel quick-release lever
4. Slide wheel out of dropouts
5. Deflate tire completely
6. Remove tire and tube from rim
7. **Keep all parts organized**

### Step 3: Install Motor in Rear Wheel

1. Take the phi-harmonic hub motor (pre-laced in 26" rim)
2. Place motor axle in rear dropouts
3. **IMPORTANT**: Motor axle has flat spots — align with dropout slots
4. Place torque arms on both sides:
   - Left torque arm: bolt to frame seat stay
   - Right torque arm: bolt to frame chain stay
5. Tighten axle nuts to 40 Nm (use torque wrench if available)
6. Reinstall tire and tube on motor rim
7. Inflate tire to 40 PSI
8. Reinstall wheel in frame
9. Reconnect brake caliper

---

## Phase 2: Install Battery (30 minutes)

### Step 4: Mount Battery Bracket

1. Position battery bracket in frame triangle
2. Mark 4 mounting holes with pencil
3. Drill 5mm holes at marked positions
4. Bolt bracket to frame using M5 bolts and nuts
5. Add rubber垫片 between bracket and frame (vibration dampening)

### Step 5: Install Battery Pack

1. Slide battery pack into bracket
2. Secure with Velcro straps
3. Add bungee cords for extra security
4. Route battery wire down seat tube
5. Connect XT60 connector to controller wire

---

## Phase 3: Install Electronics (1.5 hours)

### Step 6: Mount Controller

1. Position controller under seat (in aluminum enclosure)
2. Use 2× stainless steel hose clamps to secure
3. Ensure controller is level (for heat dissipation)
4. Route all wires neatly along frame tubes

### Step 7: Install Torque Sensor

1. Remove old bottom bracket (left side: reverse thread, right side: normal thread)
2. Clean BB shell threads with degreaser
3. Apply grease to new torque sensor threads
4. Thread sensor into BB shell:
   - Right side: clockwise
   - Left side: counter-clockwise
5. Tighten to 35-40 Nm
6. Connect signal wire to controller
7. Reinstall cranks

### Step 8: Install Throttle

1. Remove right grip from handlebar
2. Slide throttle onto handlebar
3. Position for comfortable thumb reach
4. Tighten clamp bolt
5. Route wire along top tube to controller
6. Connect to controller throttle input

### Step 9: Install Brake Levers

1. Remove old brake levers
2. Install new e-brake levers (with cut-off switches)
3. Adjust lever position for comfortable reach
4. Connect brake cut-off wires to controller
5. Adjust brake pads to rotor

### Step 10: Install LCD Display

1. Mount display bracket on handlebar (center or left)
2. Position display for easy visibility
3. Tighten clamp
4. Route display wire along top tube
5. Connect to controller display port

---

## Phase 4: Wiring (1 hour)

### Step 11: Connect Motor

1. Route motor cable along chainstay (right side)
2. Secure with zip ties every 10cm
3. Connect 3 phase wires (Blue→A, Green→B, Yellow→C)
4. Connect hall sensor connector (6-pin)
5. Double-check all connections

### Step 12: Connect Battery

1. Connect XT60 connector (red→red, black→black)
2. **Do NOT connect yet** — wait until all wiring complete
3. Secure connection with electrical tape

### Step 13: Connect Sensors

1. Connect torque sensor wire to controller
2. Connect throttle wire to controller
3. Connect brake cut-off wires to controller
4. Connect LCD display wire to controller
5. Route all wires neatly along frame
6. Secure with zip ties

### Step 14: Final Wiring Check

1. **Double-check every connection** with multimeter
2. Verify no bare wires touching frame
3. Verify no pinched wires
4. Verify all connectors are fully seated
5. Take a photo of all wiring for future reference

---

## Phase 5: Configuration & Testing (30 minutes)

### Step 15: Power Up

1. **Stand clear of the rear wheel**
2. Turn on power switch
3. Verify LCD display shows battery level
4. Verify no error codes
5. If error appears, disconnect battery and check wiring

### Step 16: Test Motor (No Load)

1. **Lift rear wheel off ground** (use kickstand or prop)
2. Turn on power
3. Gently apply throttle
4. Verify rear wheel spins smoothly
5. Verify wheel spins in correct direction (forward)
6. Listen for unusual noises (grinding, clicking)
7. **If anything sounds wrong, STOP and check wiring**

### Step 17: Test Brakes

1. With rear wheel spinning, apply brakes
2. Verify motor cuts off immediately
3. Verify wheel stops within 3 meters
4. Test both left and right brake levers

### Step 18: Test Pedal Assist

1. With rear wheel off ground, turn pedals forward
2. Verify motor activates (you should hear/feel it)
3. Verify motor cuts off when pedaling backward
4. Test all 5 assist levels on LCD

### Step 19: Test Ride

1. **Find a flat, open area with no traffic**
2. Start with assist level 1 (Eco)
3. Pedal gently and feel motor assist
4. Practice starting and stopping
5. Gradually increase assist level
6. Practice braking at slow speed
7. **Wear full protective gear**

### Step 20: Final Adjustments

1. Adjust brake pad clearance
2. Adjust display brightness
3. Set wheel diameter in controller settings
4. Set speed limit if desired (25 km/h for street legal)
5. Reset trip meter
6. **Write down your controller settings**

---

## Troubleshooting

| Problem | Solution |
|---------|----------|
| LCD won't turn on | Check battery connection, fuse |
| Motor doesn't spin | Check phase wires, hall sensors |
| Motor spins backward | Swap any 2 phase wires |
| Motor jitters/vibrates | Check hall sensor connector |
| Throttle doesn't work | Check throttle wiring, calibration |
| No pedal assist | Check torque sensor connection |
| Brakes don't cut off motor | Check brake lever switches |
| Error code on display | Look up code in controller manual |
