# PHI FTL VAN — ASSEMBLY GUIDE

## Step-by-Step Build Instructions

---

## PHASE 1: CHASSIS ASSEMBLY (35-55 hours)

### Step 1: Unibody Preparation
```
1. Lay van unibody on flat surface
2. Verify phi-spaced cross members (618mm)
3. Weld reinforcement points
4. Apply rust-preventive coating
5. Install battery cradle under cargo floor
```

### Step 2: Suspension Mounting
```
1. Install front MacPherson strut towers
2. Install rear leaf spring hangers
3. Mount front coilovers (phi-tuned)
4. Mount rear leaf springs (7-leaf packs)
5. Install anti-roll bars (φ ratio)
```

---

## PHASE 2: FPB-80 BATTERY INSTALLATION (15-25 hours)

### Step 3: Battery Connection
```
1. Mount FPB-80 in cradle
2. Connect HV main cables (40mm² orange)
3. Install HV contactor (380A)
4. Connect BMS CAN bus
5. Verify all connections
6. DO NOT ENERGIZE until Phase 4 complete
```

---

## PHASE 3: WARP FIELD SYSTEM (25-35 hours)

### Step 4: Warp Coil Installation
```
1. Mount 5 warp coils in phi-pentagon pattern
   ┌───────────────────────┐
   │         C1            │
   │        ╱  ╲           │
   │      C5    C2         │
   │      │  ●  │          │
   │      C4    C3         │
   │        ╲  ╱           │
   └───────────────────────┘
   
2. Each coil: 432μH, rated 190A peak
3. Connect coil drivers to warp controller
4. Install field emitter nodes (7× around perimeter)
5. Mount resonance stabilizer
```

---

## PHASE 4: CABIN & CARGO (25-35 hours)

### Step 5: Cabin Assembly
```
1. Install windshield and side windows
2. Mount steering column and wheel
3. Install pedal assembly
4. Mount driver and co-pilot seats
5. Route all wiring through firewall
```

### Step 6: Cargo Area
```
1. Install cargo floor (3mm steel)
2. Attach aluminum side walls
3. Install double rear doors
4. Add cargo tie-downs (16×)
5. Install cargo lights
6. Add adjustable shelf
```
