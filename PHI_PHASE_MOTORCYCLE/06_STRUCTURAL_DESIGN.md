# PHI PHASE MOTORCYCLE — Structural Design

## Frame Architecture
The motorcycle uses a carbon fiber monocoque frame designed to maintain structural integrity during phase transitions. The frame incorporates phi-spiral reinforcement ribs that distribute stress during the rapid solid-liquid-solid transitions of phase shifting.

### Frame Specifications
| Parameter | Value |
|-----------|-------|
| Material | Carbon fiber / titanium hybrid |
| Weight | 8.5 kg |
| Torsional Rigidity | 45 Nm/degree |
| Impact Rating | 30g (motorcycle standard) |
| Phase Transition Fatigue | 100,000 cycles |

### Fairing
| Parameter | Value |
|-----------|-------|
| Material | Graphene-reinforced polymer |
| Thickness | 2.5mm |
| Weight | 3.2 kg |
| Aerodynamic Drag | Cd 0.28 |
| Phase Coil Integration | Embedded, flush-mount |

## Wheel System
### Front Wheel
- **Type:** Hubless with phi-harmonic bearing
- **Diameter:** 17 inches
- **Tire:** Airless honeycomb polymer (no puncture risk)
- **Brake:** Regenerative + ceramic disc

### Rear Wheel
- **Type:** Hub motor integrated
- **Diameter:** 17 inches
- **Tire:** Airless honeycomb polymer
- **Drive:** Direct hub motor (no chain/belt)

## Phase Coil Mounting
The 6 phase coils are mounted in phi-helical positions:
- 3 coils in front fairing (integrated into headlight housing)
- 3 coils in rear tail section (integrated into taillight housing)
- Each coil: 200mm diameter, 150mm depth
- Total coil weight: 6.0 kg
- Cooling: Liquid-cooled via frame-integrated channels

## Rider Ergonomics
- **Seat Height:** 780mm (adjustable +/-30mm)
- **Handlebar Width:** 720mm
- **Footpeg Position:** Mid-set (sport-touring)
- **Rider Weight Range:** 50-120 kg
- **Harness:** 4-point quick-release (auto-engages in phase mode)

## Foldable Features
- Handlebars fold flat for storage
- Seat collapses for compact transport
- Total packed dimensions: 1.5m x 0.6m x 0.5m
- Weight with battery: 28 kg
