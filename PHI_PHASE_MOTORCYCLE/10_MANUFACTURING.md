## Manufacturing Steps

### 1. Frame Fabrication (Day 1-3)
- CNC machine titanium backbone
- Lay carbon fiber monocoque shell
- Cure in autoclave at 180C / 6 bar
- Drill mounting points and routing channels

### 2. Phase Coil Assembly (Day 2-4)
- Wind copper wire on phi-geometry mandrels
- Assemble 6 coils in phi-helical jig
- Connect to phase synchronization unit
- Test resonance frequency (target 1.618 MHz)

### 3. Drivetrain Assembly (Day 3-4)
- Install hub motor in rear wheel
- Mount regenerative brake system
- Connect cooling loop to coil array
- Test motor/controller integration

### 4. Electronics Integration (Day 4-5)
- Mount control unit and dashboard
- Wire power distribution harness
- Install barrier scanner (ultrasonic array)
- Flash firmware and run self-test

### 5. Final Assembly (Day 5-6)
- Mount fairing and body panels
- Install seat, handlebars, controls
- Connect all wiring and plumbing
- Full system integration test

### 6. Quality Assurance (Day 6-7)
- Phase coil test (barrier transit simulation)
- Load test to 200% rated capacity
- 24-hour continuous run test
- Barrier scanner calibration
- Road test (50 km minimum)
