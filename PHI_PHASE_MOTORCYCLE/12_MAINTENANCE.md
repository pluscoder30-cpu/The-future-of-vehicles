# PHI PHASE MOTORCYCLE — Maintenance Guide

## Maintenance Philosophy
The Phase Motorcycle uses solid-state phi-harmonic systems with minimal wear parts. The airless tires never need replacement under normal use, and the brushless hub motor has no wearing components.

## Maintenance Schedule

### Pre-Ride (Before Each Use, 2 min)
- [ ] Visual inspection of frame and fairing
- [ ] Phase coil status check (dashboard indicator)
- [ ] Battery level check (must be >30% for phase operations)
- [ ] Brake function test
- [ ] Tire condition check (airless — check for cuts)

### Monthly (1 hour)
- [ ] Phase coil resonance test (Q factor measurement)
- [ ] Barrier scanner calibration
- [ ] Brake pad thickness check
- [ ] Suspension function test
- [ ] Cooling system level check
- [ ] Full battery cycle (discharge/charge)

### Annual (4 hours)
- [ ] Professional inspection at authorized service center
- [ ] Phase coil deep diagnostic
- [ ] Frame integrity ultrasound scan
- [ ] Brake system overhaul
- [ ] Suspension rebuild
- [ ] Cooling system flush and refill
- [ ] Firmware major version update

### Every 5 Years
- [ ] Phase coil refurbishment ($120)
- [ ] Full system recertification
- [ ] Frame fatigue inspection
- [ ] Battery health diagnostic

## Diagnostic Mode
Hold the phase button for 10 seconds to enter diagnostic mode:
- **Green LED:** All systems nominal
- **Yellow LED:** Maintenance due soon
- **Red LED:** Immediate attention required
- **Blinking:** Error code on dashboard (consult manual)

## Storage
- Store indoors in cool, dry location
- Battery: store at 50% charge for long-term
- Connect to trickle charger if stored >30 days
- Temperature: -20C to +40C storage range
- Tire pressure: N/A (airless)
