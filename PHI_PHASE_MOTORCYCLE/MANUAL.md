## 1. Introduction
The PHI Phase Motorcycle is a two-wheeled vehicle capable of shifting its molecular phase state to pass through solid barriers. It uses 6 phi-harmonic phase coils arranged in a golden-ratio helical pattern to create phase windows that reduce the vehicle's interaction with normal matter.

## 2. Safety Information
**WARNING:** Phase shifting involves temporary reduction of material solidity. Read this manual completely before first ride.

### Required Safety Equipment
- Full-face helmet (DOT approved minimum)
- 4-point safety harness (included)
- Protective riding gear (recommended)

### Operating Limitations
- Maximum rider + cargo: 180 kg
- Maximum barrier thickness: 30 cm
- Do not phase through walls with live electrical wiring
- Do not phase in crowded areas
- 30-second cooldown between phase shifts
- Minimum age: 18 years

## 3. Pre-Ride Setup
1. Place motorcycle on level ground
2. Power on: Hold ignition button for 3 seconds
3. Wait for self-test (60 seconds)
4. Dashboard shows "READY" in green
5. Mount motorcycle
6. Fasten 4-point harness (click all 4 buckles)
7. Verify harness: Pull each strap firmly

## 4. Normal Riding Mode
- Twist throttle to accelerate
- Front brake lever: Regenerative braking
- Rear brake lever: Emergency stop
- Steering: Conventional handlebar
- Dashboard: Speed, battery, range

### Riding Modes
- **Eco:** 50% power, maximum range
- **Normal:** 75% power, balanced
- **Sport:** 100% power, aggressive
- **Phase:** 100% power, phase available

## 5. Phase Shift Mode
### Engaging Phase Shift
1. Ensure barrier ahead is within 50m
2. Press and hold phase button (left thumb)
3. Dashboard shows "PHASE READY" in gold
4. Twist throttle to >50%
5. Motorcycle enters phase state (golden glow on coils)
6. Pass through barrier
7. Release phase button after clearing barrier

### Phase Shift Rules
- 30-second cooldown between shifts
- Barrier must be >5cm and <30cm thick
- Scanner must confirm no live wires or occupants
- Rider must be harnessed

## 6. Barrier Transit
The ultrasonic scanner pre-maps the barrier. During transit:
- Motorcycle floats (tires lose contact)
- Time to pass 30cm wall: 0.18 seconds
- Rider feels no sensation
- Dashboard shows transit progress

## 7. Post-Transit
1. Phase disengages automatically
2. Tires re-engage road surface
3. 3-second stabilization period
4. Full control restored
5. Dashboard shows "PHASE CLEAR" in green

## 8. Parking and Storage
1. Come to complete stop
2. Engage kickstand
3. Power off (hold ignition 3 sec)
4. Unbuckle harness
5. Store in covered location
6. Battery: store at 50% charge

## 10. Troubleshooting
| Symptom | Likely Cause | Action |
|---------|--------------|--------|
| No phase engage | Battery <30% | Charge battery |
| Phase abort mid-transit | Barrier anomaly | Retry or find alternate route |
| Yellow warning | Maintenance due | Schedule service |
| Red warning | Fault detected | Stop, consult error code |
| Weak phase field | Coil degradation | Service required |

## 11. Emergency Procedures
### Phase Stall in Barrier
1. System attempts automatic recovery (3 tries)
2. If unsuccessful: Triple-tap phase button
3. If still stuck: Hold phase button 3 seconds (forced re-solidify)
4. Post-recovery: System check required

### Collision
1. Airbags deploy automatically
2. Engine cuts off
3. Emergency beacon activates
4. Exit vehicle when safe
5. Do not attempt to ride after collision

### Power Failure
1. Phase coils lock out (no phase possible)
2. Drive motor reduces to 30%
3. Navigate to safe stopping point
4. Contact assistance
