# PHI PHASE MOTORCYCLE — README

## Quick Start
1. Place motorcycle on level ground
2. Power on (hold ignition button 3 sec)
3. Wait for self-test (dashboard shows green)
4. Mount motorcycle, fasten harness
5. Twist throttle to ride normally
6. To phase: Hold phase button + twist throttle >50%
7. To exit phase: Release phase button or triple-tap

## Safety Warnings
- Always wear helmet and harness during phase operations
- Never phase through barriers with live electrical wires
- Do not phase in crowds or near bystanders
- Maintain 30% battery minimum for phase operations
- 30-second cooldown required between phase shifts
