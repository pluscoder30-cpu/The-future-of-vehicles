# PHI_KAYAK — Assembly Steps

> **Skill Level**: Beginner (12-year-old can do it with adult supervision)
> **Time**: 4-6 hours
> **Tools Needed**: Drill, hole saw, wrenches, screwdrivers, wire strippers, multimeter, marine sealant

---

## Phase 1: Prepare the Kayak (1 hour)

### Step 1: Inspect the Base Kayak

1. Get a used sit-on-top kayak in good condition
2. Check hull for cracks (no holes!)
3. Check drain plugs work
4. Check seat is secure
5. Check scupper holes are clear
6. **Do NOT proceed if kayak needs major repairs**

### Step 2: Mark Installation Points

1. Mark intake position: center of stern, 10cm from bottom
2. Mark exhaust position: 5cm behind intake
3. Mark battery compartment position: stern area, above waterline
4. Mark throttle position: right side of cockpit
5. Mark LED position: center of cockpit, visible from seat
6. **Use a marker that won't rub off**

---

## Phase 2: Install Water Jet (2 hours)

### Step 3: Drill Holes

1. Put on safety glasses
2. Use 50mm hole saw to drill intake hole
3. Use 50mm hole saw to drill exhaust hole
4. Sand all edges smooth
5. **Clean up all plastic shavings**

### Step 4: Install Through-Hull Fittings

1. Apply marine sealant (3M 5200) around intake hole
2. Insert intake through-hull fitting
3. Apply sealant around exhaust hole
4. Insert exhaust through-hull fitting
5. Let sealant cure for 24 hours (or use quick-cure if available)
6. **Do NOT rush this step — leaks sink kayaks**

### Step 5: Install Jet Housing

1. Connect intake grate to intake fitting
2. Connect jet housing to intake
3. Connect exhaust nozzle to exhaust fitting
4. Secure all connections with hose clamps
5. Ensure housing is straight and aligned

### Step 6: Install Motor

1. Mount motor in jet housing
2. Secure with mounting bracket
3. Connect motor wires (Blue→A, Green→B, Yellow→C)
4. Route wires through hull (use cable glands)
5. Seal all wire pass-throughs with marine sealant

---

## Phase 3: Install Battery (30 minutes)

### Step 7: Mount Battery Compartment

1. Position battery box in stern area
2. Mark mounting holes
3. Drill pilot holes
4. Bolt battery box to hull
5. Apply marine sealant around mounting bolts
6. Install waterproof hatch cover

### Step 8: Install Battery

1. Place battery in waterproof box
2. Secure with foam padding
3. Connect XT60 connector to controller wire
4. **Do NOT connect yet** — wait until all wiring complete

---

## Phase 4: Install Electronics (1 hour)

### Step 9: Mount Controller

1. Position controller in stern compartment
2. Secure with foam padding (vibration dampening)
3. Connect battery wire
4. Connect motor wires
5. Connect throttle wire
6. Connect paddle switch wire
7. Connect LED indicator wire

### Step 10: Install Throttle

1. Mount throttle bracket on right side of cockpit
2. Position for comfortable thumb reach
3. Tighten bracket bolts
4. Route throttle wire to controller
5. Seal wire pass-through with cable gland

### Step 11: Install Paddle Switch

1. Mount paddle holder in cockpit
2. Install magnetic reed switch in holder
3. Connect switch wire to controller
4. Route wire through hull
5. Seal wire pass-through with cable gland

### Step 12: Install LED Indicator

1. Mount LED on center of cockpit
2. Position for visibility from seat
3. Connect LED wires to controller
4. Route wires through hull
5. Seal wire pass-throughs with cable glands

---

## Phase 5: Final Assembly (30 minutes)

### Step 13: Wire Everything

1. Connect all wires to controller
2. **Double-check every connection** with multimeter
3. Verify no bare wires touching hull
4. Verify all cable glands are tight
5. Verify all sealant is cured

### Step 14: Test for Leaks

1. **Before connecting battery**, fill kayak with water
2. Check all through-hull fittings for leaks
3. Check all cable glands for leaks
4. Check hatch seal for leaks
5. If leaks found, apply more sealant and retest
6. **Do NOT proceed until leak-free**

### Step 15: Power Up

1. Connect battery
2. Insert paddle (enable motor)
3. Verify LED shows green (good battery)
4. Gently apply throttle
5. Verify motor spins (you'll see water jet)
6. Verify paddle switch works (remove paddle = motor stops)

### Step 16: Test Ride

1. **Find calm water** (lake, pond, slow river)
2. Put on PFD (life jacket)
3. Insert paddle (enable motor)
4. Start with Slow speed
5. Gently apply throttle and feel thrust
6. Practice starting and stopping
7. Test all 3 speed modes
8. Practice removing paddle (motor stops)
9. **Wear full safety gear**

---

## Troubleshooting

| Problem | Solution |
|---------|----------|
| LED won't turn on | Check battery connection, fuse |
| Motor doesn't spin | Check phase wires, paddle switch |
| Motor spins backward | Swap any 2 phase wires |
| Motor jitters/vibrates | Check phase wire connections |
| Throttle doesn't work | Check throttle wiring |
| Paddle switch doesn't work | Check reed switch, magnet alignment |
| Water leaks | Apply more marine sealant |
| Weak thrust | Check impeller for debris |
