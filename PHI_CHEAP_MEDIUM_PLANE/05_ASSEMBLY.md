# PHI_CHEAP_MEDIUM_PLANE — Assembly Guide

## PHASE 1: FUSELAGE FRAME (Weeks 1-4)

### Step 1.1: Build Fuselage Jig
**Tools needed**: Drill press, square, level, measuring tape

1. Cut two 4×4 lumber beams to 8000mm length
2. Mount on sawhorses, level with precision level
3. Mark station lines every 1000mm (Stations 0-8)
4. Install vertical supports at each station
5. Verify squareness with diagonal measurement (must match within 2mm)

### Step 1.2: Cut Main Frame Tubes
**Material**: 6061-T6 Aluminum square tube 1×1×1/8"

1. Cut 2× main longerons: 8000mm length
   - Mark pilot holes every 500mm for skin attachment
   - Drill 3/16" pilot holes
2. Cut 4× diagonal braces: 1200mm each
   - Cut 45° angles at each end
3. Cut 6× bulkhead rings: 1200mm diameter from 0.063" sheet
   - Mark 12 equal divisions around perimeter
   - Drill 1/8" holes for skin rivets

### Step 1.3: Assemble Fuselage Box Frame
**Method**: TIG welding (preferred) or pop rivets

1. Install Station 1 (firewall):
   - Weld/bolt V-frame to main longerons
   - Mount 0.090" firewall plate
   - Verify perpendicularity: ±1mm over 1200mm
   
2. Install Station 2-6 bulkheads:
   - Position each bulkhead at station line
   - Clamp with C-clamps
   - Drill and rivet with AD41623 pop rivets
   - Spacing: 1" between rivets
   
3. Install diagonal bracing:
   - Weld/rivet diagonal tubes between bulkheads
   - Alternating pattern for torsional rigidity
   
4. Install Station 7-8 (tail taper):
   - Progressive reduction: 1200mm → 600mm → 300mm
   - Taper angle: 8°

### Step 1.4: Install Firewall
**Material**: 0.090" aluminum plate

1. Cut to 500mm × 600mm rectangle
2. Drill mounting holes at 100mm spacing
3. Install 4× motor mount bolt holes (M8, clearance)
4. Install cable pass-throughs with grommets
5. Rivet to forward bulkhead with AD41624 rivets

### Step 1.5: Install Floor and Seat Rails
1. Cut 0.040" aluminum sheet to fit floor area
2. Install 1×1" square tube seat rails
3. Mount seat attachment points (AN3 bolts)
4. Install rudder pedal mounting brackets

## PHASE 2: WING CONSTRUCTION (Weeks 5-8)

### Step 2.1: Build Wing Jig
**Tools**: Straight edge, protractor, dial indicator

1. Set up flat building surface (minimum 8000mm × 2000mm)
2. Mark leading edge line, spar lines, trailing edge line
3. Install spar support blocks at 500mm spacing
4. Verify flatness: ±1mm over 8000mm

### Step 2.2: Cut Wing Components
**Material**: 6061-T6 aluminum

1. Main spar (2×):
   - 1.5"×1"×1/8" channel, 7000mm length
   - Drill spar bolt holes at 500mm spacing
   - 3/16" holes for rib attachment
   
2. Rear spar (2×):
   - 1"×1"×1/8" square tube, 7000mm length
   - Drill rib attachment holes
   
3. Ribs (28×):
   - 0.040" aluminum sheet
   - NACA 2412 profile template
   - Cut with nibbler or bandsaw
   - Deburr all edges
   - Drill spar attachment holes
   - Drill skin attachment holes at 25mm spacing
   
4. Leading edge (2×):
   - 0.040" aluminum sheet
   - Roll to NACA 2412 leading edge profile
   - 150mm × 1400mm development length
   
5. Trailing edge (2×):
   - 0.032" aluminum sheet
   - Form to 45° trailing edge angle

### Step 2.3: Assemble Wing Panels
**Method**: Pop rivets (AD41623)

1. Install main spar in jig
2. Attach ribs at 500mm spacing:
   - Align rib leading edge to spar
   - Drill 3/16" holes through rib and spar
   - Install AD41623 pop rivets
   - Verify rib perpendicularity
   
3. Install rear spar:
   - Align with rib trailing edge holes
   - Rivet to each rib
   
4. Install leading edge:
   - Position at rib leading edges
   - Rivet to each rib
   - Seal joint with silicone sealant
   
5. Install trailing edge:
   - Position at rib trailing edges
   - Rivet to each rib
   
6. Install wing skin (bottom first):
   - Position 0.032" sheet
   - Clamp at 100mm spacing
   - Drill and rivet to ribs and spars
   - Work from center outward
   
7. Install wing skin (top):
   - Leave inspection panels removable
   - Rivet main areas
   - Install inspection plates with Dzus fasteners

### Step 2.4: Install Flaps and Ailerons
1. Cut flap panels (0.032" skin, spar, ribs)
2. Install hinge points (piano hinge)
3. Connect control cables
4. Cut aileron panels (0.032" skin, spar, ribs)
5. Install hinge points
6. Connect control cables
7. Install counterweights (200g each)

## PHASE 3: TAIL CONSTRUCTION (Weeks 9-10)

### Step 3.1: Horizontal Stabilizer
1. Cut spar: 1"×1"×1/8" square tube, 3000mm
2. Cut ribs (10×): 0.032" aluminum, NACA 0009 profile
3. Assemble spar + ribs + trailing edge
4. Install elevator (hinged section)
5. Connect push-pull tube to elevator horn

### Step 3.2: Vertical Stabilizer
1. Cut spar: 1"×1"×1/8" square tube, 1500mm
2. Cut ribs (6×): 0.032" aluminum, NACA 0009 profile
3. Assemble spar + ribs + trailing edge
4. Install rudder (hinged section)
5. Connect push-pull tube to rudder horn

### Step 3.3: Attach Tail to Fuselage
1. Position horizontal stab on fuselage
2. Align with waterline and centerline
3. Drill and bolt with AN6 bolts (4 total)
4. Position vertical stab on fuselage
5. Align with centerline
6. Drill and bolt with AN6 bolts (4 total)
7. Verify perpendicularity: ±1mm

---

## PHASE 4: LANDING GEAR (Weeks 11-12)

### Step 4.1: Main Gear
1. Cut 4130 chrome-moly tube: 1" OD × 0.095" wall, 800mm length
2. Bend to gear geometry using hydraulic bender
   - Bend angle: 15° forward
   - Bend radius: 100mm
3. Weld mounting bracket (4130 steel, 1/4" plate)
4. Drill mounting holes: 7/16" for AN8 bolts
5. Install gear legs to fuselage:
   - 2× AN8 bolts per leg
   - Torque: 45-50 ft-lb
   - Safety wire: 0.032" stainless

### Step 4.2: Nose Gear
1. Install nose gear strut (oleo type)
2. Connect to rudder pedals via push-pull tube
3. Verify steering range: ±30°
4. Install nose wheel fork
5. Mount nose wheel

### Step 4.3: Wheels and Brakes
1. Install main wheels:
   - Mount bearings (pre-greased)
   - Torque axle nut: 25 ft-lb
   - Install cotter pin
2. Install brake calipers:
   - Mount to gear leg
   - Align with rotor
   - Connect hydraulic line
   - Bleed brake system
3. Fill brake fluid: DOT 4

---

## PHASE 5: PROPULSION (Weeks 13-16)

### Step 5.1: Motor Installation
1. Install motor mount plates:
   - 6061-T6 aluminum, 200×200×10mm
   - Drill 4× M8 holes for motor
   - Drill 4× M8 holes for firewall
2. Mount motors:
   - Align with thrust line (2° down, 1° right for left motor)
   - Torque M8 bolts: 25 ft-lb
   - Install temperature sensor
3. Install cooling:
   - Mount 80mm fan to motor housing
   - Route cooling duct
   - Connect to 12V bus

### Step 5.2: Propeller Installation
1. Balance propellers statically:
   - Mount on balancer
   - Add tape to light blade until balanced
2. Install propeller bolts:
   - 3× M12×80 Grade 10.9 bolts
   - Torque: 65 ft-lb
   - Safety wire: 0.032" stainless
3. Install spinner:
   - Align with propeller
   - Secure with screws

### Step 5.3: ESC Installation
1. Mount ESCs on firewall:
   - Use thermal pad between ESC and firewall
   - Secure with zip ties + Adel clamps
2. Connect power wires:
   - 10 AWG from battery to ESC input
   - Solder and heat-shrink all connections
3. Connect motor wires:
   - Phase wires: 10 AWG
   - Hall sensor wires: 18 AWG
   - Route away from power wires
4. Program ESCs:
   - Connect programming card
   - Set parameters:
      - Battery type: FPB-40 phi-harmonic field plasma
     - Cell count: 16S (48V)
     - Low voltage cutoff: 42V
     - Timing: auto
     - Ramp rate: soft start

## PHASE 6: ELECTRICAL SYSTEM (Weeks 17-20)

### Step 6.1: Install Battery Boxes
1. Fabricate battery boxes from 0.063" aluminum
   - Internal dimensions: 400×300×200mm each
   - Ventilation holes: 6mm diameter, 10mm spacing
2. Mount battery boxes:
   - 4× AN3 bolts per box
   - Position: station 4-5 (center fuselage)
   - Install vibration dampening: rubber grommets

### Step 6.2: Install BMS
1. Mount BMS in battery box
2. Connect balance leads:
   - Cell 1+ to BMS terminal 1
   - Cell 2+ to BMS terminal 2
   - Cell 3+ to BMS terminal 3
   - Cell 4+ to BMS terminal 4
   - Common negative to BMS terminal 0
3. Connect temperature sensor:
   - NTC thermistor to BMS temp input
   - Position on battery case

### Step 6.3: Install Main Electrical
1. Install main bus bars:
   - Left bus: 200A copper, mounted on insulating standoffs
   - Right bus: 200A copper, mounted on insulating standoffs
2. Install master relay:
   - 200A contactor, mounted on firewall
   - Connect coil to master switch
3. Install circuit breakers:
   - Mount on instrument panel
   - Label each breaker
4. Run wiring:
   - Follow wire routing rules from 02_WIRING.md
   - Secure with Adel clamps every 150mm
   - Label every wire at both ends

### Step 6.4: Install Avionics
1. Mount instrument panel:
   - 0.063" aluminum sheet
   - Cut instrument holes
2. Install instruments:
   - Airspeed indicator
   - Altimeter
   - Vertical speed indicator
   - Turn coordinator
   - Heading indicator
   - Compass
3. Mount GPS bracket
4. Install VHF radio
5. Install ELT:
   - Mount on rear fuselage
   - Connect antenna
   - Connect to 12V bus with 2A breaker

### Step 6.5: Install Lighting
1. Install landing light:
   - Mount on nose gear strut
   - Connect to 12V bus with 10A breaker
2. Install nav lights:
   - Red: left wingtip
   - Green: right wingtip
   - White: tail
   - Connect to 12V bus with 5A breaker
3. Install strobe:
   - Mount on tail
   - Connect to nav light circuit

## PHASE 7: CONTROL SYSTEM (Weeks 21-24)

### Step 7.1: Install Flight Controls
1. Install control sticks:
   - Mount in cockpit floor
   - Connect push-pull tubes
2. Install rudder pedals:
   - Mount on forward fuselage
   - Connect push-pull tubes
3. Install flap handle:
   - Mount on center console
   - Connect cable to flaps
4. Install trim system:
   - Mount linear actuator on elevator
   - Connect trim switch to panel
   - Calibrate: full range ±10°

### Step 7.2: Route Control Cables
1. Aileron cables:
   - From stick to left aileron
   - From stick to right aileron
   - Route through pulleys
   - Adjust turnbuckles for tension
2. Elevator cables:
   - From stick to elevator horn
   - Route through pulleys
3. Rudder cables:
   - From pedals to rudder horn
   - Route through pulleys
4. Flap cables:
   - From handle to flap actuator
   - Route through pulleys

### Step 7.3: Adjust Controls
1. Set neutral positions:
   - Ailerons: 0°
   - Elevator: 0°
   - Rudder: 0°
2. Verify full travel:
   - Ailerons: ±25°
   - Elevator: ±25°
   - Rudder: ±30°
   - Flaps: 0-45°
3. Check for binding:
   - Move each control through full range
   - Should move freely
4. Safety wire all turnbuckles

---

## PHASE 8: FINAL ASSEMBLY (Weeks 25-28)

### Step 8.1: Attach Wings
1. Position wing on fuselage
2. Align with incidence angle (3°)
3. Install 4× AN6 bolts per side
4. Torque: 25-30 ft-lb
5. Safety wire all bolts
6. Connect aileron and flap cables
7. Connect wiring (landing light, nav light)

### Step 8.2: Attach Empennage
1. Position horizontal stab
2. Align with incidence angle (0°)
3. Install 4× AN6 bolts
4. Torque: 25-30 ft-lb
5. Safety wire all bolts
6. Position vertical stab
7. Align with centerline
8. Install 4× AN6 bolts
9. Torque: 25-30 ft-lb
10. Connect rudder and elevator cables

### Step 8.3: Install Doors
1. Cut door openings in fuselage skin
2. Install piano hinges
3. Install door latches
4. Install door seals (rubber)
5. Verify latching mechanism

### Step 8.4: Install Seats
1. Install seat rails
2. Mount seats
3. Install seat belts (4-point harness)
4. Verify adjustment range

### Step 8.5: Final Inspection
1. Check all bolts for torque
2. Check all safety wire
3. Check all wiring connections
4. Check all control movements
5. Check all circuit breakers
6. Fill out inspection checklist
7. Schedule A&P inspection
