# PHI_CHEAP_MEDIUM_PLANE — Quick Start Guide

## Project Summary
Build a dirt-cheap4-6 seat twin-engine phi-harmonic aircraft for under $8,000.

## Quick Reference

| Parameter | Value |
|---|---|
| Empty weight | 800 kg |
| MTOW | 1360 kg |
| Passengers | 4-6 (pilot + 3-5) |
| Range | 564 km |
| Cruise speed | 200 km/h |
| Max speed | 250 km/h |
| Power | 2× 30 kW motors |
| Batteries | 8× FPB-40 phi-harmonic field plasma batteries (160 kWh total) — Zero fire/explosion risk — plasma is self-limiting |
| Cost target | $7,500 |

## Safety Warning
**This is an experimental amateur-built aircraft.** Construction requires:
- Mechanical skills
- Electrical skills
- Welding capability
- Tool access (see 01_PARTS_LIST for required tools)
- Minimum 500 hours build time
- A&P mechanic for final inspection
- FAA airworthiness certificate required
