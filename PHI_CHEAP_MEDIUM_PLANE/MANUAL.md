# PHI CHEAP MEDIUM PLANE — Kid-Friendly Instruction Manual

## What Is the PHI Cheap Medium Plane?

The PHI Cheap Medium Plane is a **twin-engine airplane** that can carry 4-6 people! It's like a mini airliner that you build yourself in a big garage or hangar. It has TWO motors instead of one, which means if one motor fails, the other one keeps you flying safely.

This is the biggest and most complex of all four builds. It's like building a house AND a car at the same time — but cooler because it flies!

### Why Two Motors?

| Reason | What It Means |
|--------|--------------|
| **Safety** | If one motor fails, the other keeps flying |
| **Less stress** | Each motor works at 30 kW instead of one at 60 kW |
| **Balanced push** | Two motors = smoother, quieter flight |
| **Redundancy** | Two batteries, two controllers, two of everything |

## Step-by-Step Assembly

### Phase 1: Build the Fuselage (Weeks 1-4)

The fuselage is the body of the plane — it holds the passengers, batteries, and all the important stuff.

**Step 1:** Build the fuselage jig
- Cut two 4×4 lumber beams to 8 meters
- Mount on sawhorses and level them
- Mark station lines every 1 meter
- This is your building reference — it must be perfectly level!

**Step 2:** Cut the main frame tubes
- Cut 2× main longerons: 8 meters each
- Cut 4× diagonal braces: 1200mm each (with 45° angles)
- Cut 6× bulkhead rings: 1200mm diameter from sheet aluminum

**Step 3:** Weld the fuselage box frame
- Start with the firewall (Station 1)
- Weld V-frame to main longerons
- Install bulkheads at each station
- Add diagonal bracing between bulkheads
- Weld the tail taper (Stations 7-8)

```
 FUSELAGE BUILD ORDER:
 ═══════════════════════════════════════

 Station:  0    1    2    3    4    5    6    7    8
           │    │    │    │    │    │    │    │    │
           │ FW │    │    │    │    │    │ TW │TW  │
           │    │    │    │    │    │    │    │    │
     ══════╪════╪════╪════╪════╪════╪════╪════╪════╪════
     │     │    │    │    │    │    │    │    │    │     │
     ══════╪════╪════╪════╪════╪════╪════╪════╪════╪════
           │    │    │    │    │    │    │    │    │

 FW = Firewall (0.090" aluminum plate)
 TW = Tail wedge (tapering down)
 Total length: 8 meters (26 feet!)
```

**Step 4:** Install the firewall
- Cut 0.090" aluminum plate to 500×600mm
- Drill mounting holes
- Install motor mount bolt holes (M8)
- Rivet to forward bulkhead

**Step 5:** Install floor and seat rails
- Cut 0.040" aluminum sheet for floor
- Install 1×1" square tube seat rails
- Mount seat attachment points
- Install rudder pedal brackets

---

### Phase 2: Build the Wings (Weeks 5-8)

**Step 6:** Build the wing jig
- Set up a flat building surface (8m × 2m minimum)
- Mark leading edge line, spar lines, trailing edge line
- Verify flatness: ±1mm over 8 meters

**Step 7:** Cut wing components
- Main spars: 1.5"×1"×1/8" aluminum channel, 7m each
- Rear spars: 1"×1"×1/8" square tube, 7m each
- Ribs: 28 pieces, cut from 0.040" aluminum sheet
- Leading edge: 0.040" aluminum, rolled to shape
- Trailing edge: 0.032" aluminum, formed to 45° angle

**Step 8:** Assemble wing panels
- Install main spar in jig
- Attach ribs at 500mm spacing (rivets)
- Install rear spar
- Install leading edge (rivet to each rib)
- Install trailing edge (rivet to each rib)
- Install bottom skin first (rivet to ribs and spars)
- Install top skin (leave inspection panels removable)

**Step 9:** Install flaps and ailerons
- Flaps: inboard 50% of wing, 45° deflection
- Ailerons: outboard 50% of wing, ±25° deflection
- Connect control cables through wing

### Phase 3: Build the Tail (Weeks 9-10)

**Step 10:** Build horizontal stabilizer
- 3000mm span, 800mm chord
- NACA 0009 airfoil (symmetric — same top and bottom)
- Build same method as wing (spar + ribs + skin)
- Install elevator (hinged section)

**Step 11:** Build vertical stabilizer
- 1500mm height, 1000mm chord
- Same construction method
- Install rudder (hinged section)

**Step 12:** Attach tail to fuselage
- Bolt horizontal stab with 4× AN6 bolts
- Bolt vertical stab with 4× AN6 bolts
- Connect rudder and elevator cables

### Phase 4: Build Landing Gear (Weeks 11-12)

**Step 13:** Build main gear legs
- Cut 4130 chrome-moly tube: 1" OD, 800mm long
- Bend with hydraulic bender (15° forward)
- Weld mounting bracket (1/4" steel plate)
- Install to fuselage with 2× AN8 bolts per leg

**Step 14:** Install nose gear
- Mount oleo strut (absorbs landing bumps)
- Connect to rudder pedals (steerable!)
- Install nose wheel fork and wheel

**Step 15:** Install brakes
- Mount hydraulic disc brakes on main wheels
- Connect hydraulic lines
- Bleed brake system (like a car)
- Fill with DOT 4 brake fluid

### Phase 5: Install Motors & Propellers (Weeks 13-16)

**Step 16:** Mount the motors
- Install motor mount plates on firewall
- Bolt motors with M8 Grade 10.9 bolts
- Align thrust line: 2° down, 1° right for left motor
- Install cooling fans

**Step 17:** Install propellers
- Balance each propeller statically
- Install with 3× M12×80 Grade 10.9 bolts
- Torque to 65 ft-lb
- Safety wire all bolts
- Install spinners

**Step 18:** Install ESCs (motor controllers)
- Mount on firewall with thermal pads
- Connect power wires (10 AWG from battery)
- Connect motor phase wires (10 AWG)
- Connect hall sensor wires (18 AWG)
- Program ESCs: phi-harmonic field plasma, 16S (48V), soft start

### Emergency Procedures

**Single engine failure:**
1. Maintain 120 km/h airspeed
2. Rudder: correct yaw toward dead engine
3. Reduce remaining engine to 80%
4. Declare emergency on VHF (121.5 MHz)
5. Squawk 7700 on transponder
6. Divert to nearest airport
7. Single-engine landing

**Complete power failure:**
1. Best glide speed: 100 km/h
2. Activate emergency battery
3. ELT auto-activates on impact
4. Radio: declare emergency
5. GPS: navigate to nearest landing area
6. Select field: 800m+ runway, into wind
7. Flaps: 30°
8. Doors: unlatched
9. Execute emergency landing
10. After landing: master OFF, evacuate, move away

**Fire:**
1. Master switch OFF
2. Battery switches OFF
3. Fire extinguisher into engine area
4. Land immediately
5. Evacuate all occupants
6. Move 50m upwind

**Battery thermal runaway:**
1. Master OFF immediately
2. Battery switches OFF
3. Do NOT open battery boxes
4. Land immediately
5. Evacuate and move 50m away
6. Do NOT attempt to fight phi-harmonic field plasma fire — plasma is self-limiting (zero fire/explosion risk)

| One motor won't start | ESC error or motor fault | Check ESC, check motor windings |
| Both motors vibrate | Propeller imbalance | Rebalance both propellers |
| Plane pulls left | Asymmetric thrust | Adjust motor mount alignment |
| Battery voltage drops fast | Battery capacity loss | Load test batteries, replace weak ones |
| GPS won't lock | Antenna blocked | Reposition antenna on top of fuselage |
| Radio static | Antenna loose | Check antenna connection |
| Brakes weak | Air in hydraulic lines | Bleed brake system |
| Controls feel sloppy | Cable tension low | Adjust turnbuckles |
| ELT won't arm | Battery low | Replace ELT battery |
| Trim not working | Actuator failed | Check wiring, replace actuator |
