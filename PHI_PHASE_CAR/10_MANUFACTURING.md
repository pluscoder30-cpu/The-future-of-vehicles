## Manufacturing Steps

### 1. Body Fabrication (Day 1-5)
- CNC machine aluminum subframe
- Lay carbon fiber monocoque shell
- Cure in autoclave at 180C / 8 bar
- Apply graphene-composite outer skin
- Drill phase coil mounting points

### 2. Phase Coil Assembly (Day 3-6)
- Wind copper wire on phi-geometry mandrels
- Assemble 12 coils in phi-dodecahedral jig
- Connect to containment synchronizer
- Test resonance frequency (target 1.618 MHz)
- Balance all 12 coils within 1%

### 3. Drivetrain Assembly (Day 5-7)
- Install 4 hub motors in wheels
- Mount regenerative brake system
- Connect cooling loops
- Test motor/controller integration
- Align all 4 wheels to within 0.1 degrees

### 4. Electronics Integration (Day 6-8)
- Mount AI computer and dashboard
- Wire power distribution harness
- Install barrier scanner (16-element array)
- Flash AI navigation software
- Run full system self-test

### 5. Interior Assembly (Day 8-9)
- Install seats and trim
- Mount HVAC system
- Connect entertainment system
- Install airbag system
- Test all occupant systems

### 6. Final Assembly (Day 9-10)
- Mount body to subframe
- Connect all wiring and plumbing
- Install glass and seals
- Full system integration test

### 7. Quality Assurance (Day 10-12)
- Phase containment test (barrier simulation)
- Load test to 200% rated capacity
- 48-hour continuous run test
- Barrier scanner calibration
- Road test (200 km minimum)
- Crash simulation (virtual)
- Phase transit test (30cm wall)
