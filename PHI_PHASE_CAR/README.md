# PHI PHASE CAR — README

## Quick Start
1. Approach vehicle (auto-unlock via phone)
2. Enter and sit in any seat
3. Fasten seatbelt (automatic tensioning)
4. Press power button (dashboard lights up)
5. AI system self-test (90 seconds)
6. Select driving mode (Normal recommended)
7. Drive normally using steering and pedals
8. For phase: Press phase button + AI authorization
9. For autonomous: Select Autonomous mode

## Safety Warnings
- All passengers must wear seatbelts during phase operations
- Never phase through barriers with live electrical wires
- Do not phase in crowded areas
- Maintain 30% battery minimum for phase operations
- 45-second cooldown required between phase shifts
- Children under 12 must sit in rear seats
