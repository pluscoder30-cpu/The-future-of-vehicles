# PHI SYNTHETIC WINGS — Maintenance Guide

## Maintenance Philosophy
The Synthetic Wings are a life-critical flight system. Maintenance is thorough and mandatory — no shortcuts, no delays.

## Maintenance Schedule

### Pre-Flight (Before Each Flight, 5 min)
- [ ] Visual inspection of wing frames (cracks, bends)
- [ ] Feather integrity check (no missing/damaged feathers)
- [ ] Harness inspection (webbing, buckles, stitching)
- [ ] Parachute pin check (armed)
- [ ] Battery level check (must be >50% for flight)
- [ ] Servo function test (full range of motion)
- [ ] Control response test (all axes)
- [ ] Emergency systems test

### After Each Flight
- [ ] Wipe down wing surfaces
- [ ] Inspect feathers for damage
- [ ] Check harness for wear
- [ ] Log flight (duration, battery usage, issues)

### Monthly (4 hours)
- [ ] Full servo calibration
- [ ] Lift emitter resonance test
- [ ] Harness load test
- [ ] Parachute system inspection
- [ ] Battery full cycle test
- [ ] Control system calibration
- [ ] Structural ultrasound scan

### Annual (16 hours)
- [ ] Professional inspection at authorized service center
- [ ] Wing frame fatigue inspection
- [ ] Servo motor overhaul
- [ ] Lift emitter deep diagnostic
- [ ] Parachute repack (if due)
- [ ] Harness replacement (if worn)
- [ ] Full system recertification
- [ ] 50-flight test program

### Every 5 Years
- [ ] Complete frame re-certification
- [ ] Feather replacement ($50)
- [ ] Parachute replacement
- [ ] Full system rebuild

## Storage
- Store folded in backpack
- Keep in cool, dry location
- Battery: store at 50% charge
- Parachute: inspect every 6 months
- Feathers: avoid prolonged UV exposure
- Frame: hang or lay flat (no bending)
