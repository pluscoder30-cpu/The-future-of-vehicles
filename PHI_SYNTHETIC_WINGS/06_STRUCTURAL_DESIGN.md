# PHI SYNTHETIC WINGS — Structural Design

## Wing Architecture
The Synthetic Wings use a carbon fiber frame with flexible polymer "feathers" that create a biomimetic wing surface. The frame is articulated to allow natural flapping motion.

### Frame Specifications
| Parameter | Value |
|-----------|-------|
| Material | Carbon fiber / titanium hybrid |
| Wingspan | 5.0 meters |
| Wing Chord | 600mm (average) |
| Frame Weight | 4.0 kg (pair) |
| Feather Weight | 1.5 kg (pair) |
| Total Wing Weight | 5.5 kg |
| Fatigue Life | 100,000 flapping cycles |
| Maximum Load | 200 kg (wearer) |

### Feather System
| Parameter | Value |
|-----------|-------|
| Material | Flexible polymer (self-healing) |
| Shape | Bird-like (individual feathers) |
| Number | 24 primary, 48 secondary |
| Overlap | 30% (continuous surface) |
| Flexibility | 180-degree bend radius |
| Self-Healing | Yes (2-8 hours for cuts) |

## Harness System
- **Type:** Full-body harness (like paragliding)
- **Attachment:** 6-point connection to wing frame
- **Padding:** Memory foam with graphene thermal regulation
- **Quick-Release:** Single-lever emergency release
- **Load Rating:** 15 kN per attachment point
- **Weight:** 2.5 kg

## Backpack Unit
- **Housing:** Carbon fiber shell
- **Contents:** Battery, flight computer, safety systems
- **Weight:** 5.0 kg (with battery)
- **Ventilation:** Passive cooling (no fans)
- **Emergency:** Parachute container (integrated)

## Foldable Architecture
The wings fold flat for ground transport:
1. Feathers fold inward (auto)
2. Wing frame folds at mid-joint
3. Wings collapse against backpack
4. Total packed size: 1.2m x 0.6m x 0.3m
5. Deploy time: 10 seconds
6. Pack time: 15 seconds
