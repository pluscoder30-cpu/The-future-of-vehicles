# PHI SYNTHETIC WINGS — README

## Quick Start
1. Unpack backpack, unfold wings (10 seconds)
2. Put on harness, secure all 6 buckles
3. Connect battery to backpack
4. Power on (hold button 3 sec)
5. Wait for self-test (30 seconds)
6. Step into open area
7. Start flapping — wings amplify your motion
8. To hover: Stop flapping, wings auto-hover
9. To land: Reduce flapping, descend gently
10. Emergency: Pull red handle (parachute)

## Safety Warnings
- Always wear harness (all 6 buckles)
- Always check parachute before flight
- Maintain 50% battery minimum for flight
- Do not fly in winds >40 km/h
- Do not fly in rain or poor visibility
- Practice emergency procedures before first flight
- Minimum age: 18 years
