## Battery Safety Quick Reference

| Rule | Why |
|------|-----|
| Never charge unattended | LiFePO4 can thermal-runaway if damaged |
| Use BMS (Battery Management System) | Prevents overcharge/overdischarge |
| Store at 50-60% charge | Maximum shelf life |
| Never puncture or crush cells | Can cause fire |
| Keep away from metal objects | Short circuit = fire |
| Use correct charger voltage | Wrong voltage = fire |
| Inspect before each use | Swollen/damaged = replace immediately |
| Dispose at recycling center | Never in regular trash |

## Maintenance Schedule

### Monthly

- Inspect all bolts for tightness
- Check tire pressure (pneumatic models)
- Clean electrical contacts
- Test brakes
- Charge battery to 50-60% for storage

### Quarterly

- Inspect wiring for wear/damage
- Check battery voltage (all cells balanced?)
- Lubricate moving parts
- Inspect wheels/bearings for wear
- Test all safety features

### Annually

- Replace worn wheels/bearings
- Inspect frame for cracks/fatigue
- Replace brake pads if worn
- Test battery capacity (compare to original)
- Recalibrate sensors if needed

## Emergency Procedures

| Situation | Action |
|-----------|--------|
| Battery smoking | Move away, do not touch, call fire dept |
| Motor overheating | Stop immediately, let cool 30 min |
| Brake failure | Step off/abandon, use secondary brake |
