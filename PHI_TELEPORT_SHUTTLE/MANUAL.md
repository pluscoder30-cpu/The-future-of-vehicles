# PHI_TELEPORT_SHUTTLE — Quick Start Manual

## What Is This?

The PHI_TELEPORT_SHUTTLE (PTS-1) is a teleportation spacecraft. It doesn't "move through space" — it folds the spatial dimension so that two points (even 15,000 km apart) become the same point. Then you're there.

**Think of it like folding a piece of paper.** If you're at one corner and want to get to the opposite corner, instead of walking across, you fold the paper so the corners touch. Then you just step across.

---

## Before You Start

### What You Need

- 2 people (pilot + copilot)
- 4× FPB-100 batteries (fully charged — 400 kWh total)
- Liquid nitrogen (50L dewar, full)
- Navigation target (GPS coordinates or address)
- Ground control clearance

### Safety First

| Rule | Why |
|------|-----|
| Always have 2 crew | One flies, one monitors |
| Never fold during active fold at target | Fold conflict |
| Keep coils below 120°C | Superconductor quench |
| Keep batteries above 20% | Insufficient fold energy |
| Stay in cocoon during fold | Radiation protection |
| 30-second post-fold wait | Metric relaxation |

## Quick Start Sequence

### Step 1: Power Up (3 minutes)

```
1. Turn on main disconnect switches (both)
2. Verify batteries at 100% (voltage monitors)
3. Turn on auxiliary bus
4. Wait for voltage to stabilize
```

### Step 2: Cool Coils (30 minutes)

```
1. Open LN2 valve to coil system
2. Wait for coils to reach 77K (temperature display)
3. Verify all 12 coils at operating temperature
4. Close LN2 valve to standby flow
```

### Step 3: System Startup (2 minutes)

```
1. Press START button (green)
2. System runs self-test:
   - Fold coils: ✓
   - Navigation: ✓
   - Safety systems: ✓
   - Communication: ✓
   - Life support: ✓
3. Wait for "SYSTEMS READY" on display
```

### Step 4: Enter Target Location (1 minute)

```
1. On navigation display, enter target:
   Method A: GPS coordinates (lat, lon)
   Method B: Address / landmark name
   Method C: Visual target (camera lock)

2. Press VALIDATE
   - System checks: ✓ within range (0-15,000 km)
   - System checks: ✓ target clear (3m × 3m × 3m)
   - System checks: ✓ fold node density sufficient

3. Press LOCK TARGET
   - Fold node map appears
   - Status: ● READY
```

### Step 5: Pre-Fold Checklist (2 minutes)

```
□ All systems nominal
□ Batteries at 100%
□ Coils at 77K
□ Target validated and locked
□ Fold clearance received
□ Communication link established
□ Passenger brief completed
□ Safety harnesses checked
□ Fold cocoons deployed
□ Cargo bay secured
```

### Step 6: Initiate Fold (0.5 seconds)

```
1. Pilot: "Fold initiation, [target coordinates]"
2. Copilot: "Confirmed, [target coordinates]"
3. Pilot presses GREEN FOLD button
4. Watch display:

   FOLD STATUS: ● FORMING
   Fold Nodes:  ● FORMING (vehicle, target)
   Fold Bridge: ● FORMING
   Energy:      ● 86.7 kWh consumed

5. Wait 2.5 seconds for fold to stabilize

   FOLD STATUS: ● READY
   Fold Bridge: ● STABLE
```

### Step 7: Transit (0.8 seconds)

```
1. Pilot: "Commencing transit"
2. Copilot: "Confirmed"
3. Press GREEN TRANSIT button
4. Transit happens in 0.8 seconds
5. Passenger experience: instantaneous spatial shift

   FOLD STATUS: ● TRANSIT
   Transit:     ● COMPLETE
```

### Step 8: Post-Fold Verification (1 minute)

```
1. Check position on GPS
2. Verify metric flat (coherence sensor)
3. Verify coils cooling down
4. Verify battery status
5. Verify communication link
6. Verify life support
7. Verify passenger status
8. Verify cargo bay
9. Log fold event
10. Notify ground control (if required)

⚠️ WAIT 30 SECONDS before moving (metric relaxation)
```

## Emergency Procedures

### Fold Abort (if something goes wrong)

```
1. Press RED FOLD ABORT button (either crew)
2. System automatically:
   - Cuts power to all coils (50ms)
   - Activates quench switches (100ms)
   - Dumps energy to heat sinks (500ms)
   - Verifies metric flat (1 sec)
3. Vehicle returns to starting position
4. Assess situation, decide: retry or return to base
```

### Fire

```
1. Announce: "Fire, [location]"
2. Initiate fold abort (if in fold)
3. Shut down coils and batteries
4. Activate fire suppression
5. Open emergency exits
6. Evacuate passengers
7. Move to 50m safe distance
8. Notify emergency services
```

### Communication Failure

```
1. Attempt radio on all frequencies
2. Attempt quantum-linked comms
3. Activate emergency beacon (121.5 MHz + 406 MHz)
4. Return to base (if possible)
```

## Tips

1. **Short folds use less energy.** A 10 km fold uses 86.7 kWh. A 15,000 km fold uses 250 kWh.
2. **Keep coils cold.** If coils warm above 77K, wait for re-cool before folding.
3. **Verify target clearance.** The target needs a 3m × 3m × 3m clear volume.
4. **Log every fold.** Data helps with maintenance and calibration.
5. **Trust the cocoon.** It protects you from fold radiation. Stay inside during transit.
6. **Wait 30 seconds after fold.** The spatial metric needs time to relax to flat.
