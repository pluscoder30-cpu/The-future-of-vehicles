# Propulsion System — Phi-Harmonic Teleportation Coils

## 1. System Overview

The teleport shuttle has no conventional propulsion system. It does not move through space — it teleports. The "propulsion system" is therefore the **teleportation coil array** that creates the fold bridge between the vehicle's current position and the target position.

### 2.3 Phi-Harmonic Drive

Each coil is driven by a **phi-harmonic oscillator** that generates the standing wave at the phi-related frequencies:

```
Drive signal: V(t) = Σ Aₙ · sin(ω₀ · φⁿ · t + φₙ)
```

where:
- Aₙ is the amplitude of the nth harmonic
- ω₀ is the fundamental frequency (100 kHz)
- φⁿ is the golden ratio raised to the nth power
- φₙ is the phase offset for the nth harmonic

The first three harmonics are:
- n=0: 100 kHz (fundamental — fold initiation)
- n=1: 161.8 kHz (φ-harmonic — fold stabilization)
- n=2: 261.8 kHz (φ²-harmonic — fold coherence)

## 3. Fold Node Generation

### 3.1 Primary Fold Node

The primary fold node is generated at the vehicle's center of mass. All 12 coils phase-lock to create a constructive interference pattern at this point:

```
Ψ_primary(r=0) = Σ Aₙ · exp(i · ω₀ · φⁿ · t)
```

At the center, all phases align, creating a peak field amplitude of:

```
Ψ_peak = 12 × A₁ × φ ≈ 12 × 500 kV/m × 1.618 ≈ 9.71 MV/m
```

### 3.2 Remote Fold Node

The remote fold node (at the target location) is generated by a subset of coils (C01, C04, C07, C10) that phase-shift their output to project the fold field outward. The remote node is formed at distance D when:

```
k · D = 2π · n · φ
```

where k is the wavevector and n is an integer. For D = 10 km:

```
k = 2π · n · φ / D ≈ 1.017 × 10⁻³ rad/m (for n=1)
```

### 3.3 Fold Bridge Formation

Once both fold nodes are established, the fold bridge forms spontaneously through **metric resonance coupling**. The two nodes are phi-harmonically coupled — oscillations at one node propagate to the other through the folded metric.

The bridge formation time is:

```
τ_bridge = D / (c · φ⁻¹) ≈ D / (0.618c)
```

For D = 10 km:

```
τ_bridge ≈ 10,000 / (0.618 × 3×10⁸) ≈ 54 μs
```

## 4. Fold Coil Control System

### 4.1 Phase-Lock Loop

Each coil has an independent phase-lock loop (PLL) that locks to the master oscillator:

```
Error signal: e(t) = θ_ref(t) - θ_coil(t)
Control signal: u(t) = Kp · e(t) + Ki · ∫e(t)dt + Kd · de(t)/dt
```

The PID gains are tuned for phi-harmonic response:
- Kp = 1.0 (proportional)
- Ki = 1/φ ≈ 0.618 (integral)
- Kd = 1/φ² ≈ 0.382 (derivative)

### 4.2 Fold Alignment System

The fold alignment system continuously monitors:
- Fold node position (GPS + inertial)
- Fold bridge integrity (metric coherence sensor)
- Fold field amplitude (B-field probes)
- Fold frequency stability (FFT analyzer)

If any parameter deviates beyond tolerance, the alignment system adjusts coil phases to correct the error. The correction bandwidth is 10 kHz — fast enough to compensate for vehicle motion during fold transit.
