## QUICK START

### Prerequisites

- 3D printer (Ender 3 V2 or similar)
- Soldering iron (temperature-controlled)
- Basic electronics tools
- ~$600 for parts

### Build Steps

1. **Order parts** — See `01_PARTS_LIST.md` for complete BOM
2. **Print housing** — See `03_MECHANICAL.md` for STL files and settings
3. **Assemble electronics** — See `05_ASSEMBLY.md` for step-by-step guide
4. **Wire everything** — See `02_WIRING.md` for complete wiring diagrams
5. **Flash firmware** — Download from releases, flash via USB
6. **Calibrate** — See calibration section in `05_ASSEMBLY.md`
7. **Go interdimensional!**
