## Manufacturing Steps

### 1. Hull Fabrication (Day 1-7)
- CNC machine titanium frame rings
- Lay carbon fiber pressure hull
- Cure in autoclave at 200C / 10 bar
- Machine viewport opening
- Install reinforcement ribs

### 2. Viewport Installation (Day 5-6)
- Cast acrylic dome in pressure mold
- Polish optical surfaces
- Install in hull with triple O-ring seal
- Pressure test to 1500m (3x rated)

### 3. Field Array Assembly (Day 3-5)
- Wind copper wire on phi-geometry mandrels
- Assemble 4 arrays in phi-helical jig
- Connect to field synchronizer
- Test resonance frequency (target 1.618 MHz)

### 4. Systems Integration (Day 7-9)
- Install battery in pressure vessel
- Mount control unit and dashboard
- Wire power distribution harness
- Install life support and ballast
- Connect acoustic communications

### 5. Final Assembly (Day 9-10)
- Install seats and interior
- Connect all wiring and plumbing
- Seal hull penetrations
- Full system integration test

### 6. Quality Assurance (Day 10-14)
- Pressure test to 1500m (24 hours)
- Leak detection (helium mass spectrometry)
- Field skimmer function test
- Life support endurance test (4 hours)
- Emergency ascent test
- Acoustic communication test
- 50-dive test program
