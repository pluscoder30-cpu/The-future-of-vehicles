    |    +---------+    |
    |         |         |
    +---------+---------+

    SEAL METHOD:
    1. Grease O-ring with silicone
    2. Seat in groove (3mm deep x 5mm wide)
    3. Compress flange with 8x M6 bolts
    4. Torque bolts in star pattern to 5 Nm
