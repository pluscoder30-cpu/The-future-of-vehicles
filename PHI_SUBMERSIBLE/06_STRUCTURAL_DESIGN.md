# PHI SUBMERSIBLE — Structural Design

## Hull Architecture
The Submersible uses a carbon fiber / titanium pressure hull designed for deep-water operations. The hull incorporates phi-spiral reinforcement ribs that distribute pressure loads evenly across the structure.

### Hull Specifications
| Parameter | Value |
|-----------|-------|
| Material | Carbon fiber / titanium hybrid |
| Thickness | 25mm (pressure hull) |
| Weight | 85 kg (hull only) |
| Maximum Depth | 500m (50 bar) |
| Safety Factor | 3x (rated to 1500m) |
| Impact Rating | 30g |
| Fatigue Life | 50,000 dive cycles |

### Exterior
| Parameter | Value |
|-----------|-------|
| Length | 3,500 mm |
| Width | 1,800 mm |
| Height | 1,600 mm |
| Dry Weight | 180 kg |
| Displacement | 350 kg (in water) |
| Buoyancy | Positive (with ballast) |

## Viewport
- **Type:** Acrylic dome, panoramic
- **Diameter:** 1,200mm
- **Thickness:** 80mm (rated to 500m)
- **Visibility:** 180 degrees horizontal, 120 degrees vertical
- **Defogging:** Phi-harmonic thermal coating

## Pressure Seals
- **Hull penetration:** Triple O-ring seals
- **Access hatch:** Hydraulically actuated, 1-bar seal
- **Electrical penetrators:** Oil-filled, pressure-balanced
- **Fiber optic ports:** For external cameras and sensors

## Ballast System
- **Type:** Variable buoyancy (pump + drop weights)
- **Buoyancy Control:** +/-50 kg displacement
- **Drop Weights:** 2x 25kg, electrically released
- **Emergency:** All weights drop simultaneously (positive buoyancy)
- **Surface:** Blow compressed air to ballast tanks (if equipped)

## Interior
- **Seating:** 2 occupants (side-by-side)
- **Space:** 2.0 m x 1.2 m x 1.0 m
- **Visibility:** Panoramic dome viewport
- **Climate:** Heated, dehumidified
- **Audio:** Bone-conduction comms (no speakers)
