# PHI SUBMERSIBLE — Propulsion System

## Field Propulsion
The Submersible does not use propellers. Instead, the phi-harmonic field skimmer creates a directional pressure gradient by asymmetrically modulating the field envelope. This generates thrust without any moving parts in the water.

## Propulsion Specifications
| Parameter | Value |
|-----------|-------|
| Type | Phi-harmonic field propulsion |
| Number of Emitters | 4 arrays (port, starboard, bow, stern) |
| Continuous Thrust | 500 N |
| Peak Thrust | 2,000 N |
| Top Speed (Surface) | 30 km/h |
| Top Speed (Submerged) | 25 km/h |
| Emergency Ascent | 10 m/s (30 seconds) |

## Phi-Harmonic Field Skimmer
| Parameter | Value |
|-----------|-------|
| Field Type | Boundary layer modification |
| Field Thickness | 2 mm (around entire hull) |
| Drag Reduction | 98% |
| Field Frequency | 1.618 MHz |
| Field Strength | 1.2 T at hull surface |
| Coverage | 100% of wetted surface |
| Power Consumption | 5 kW continuous |

## Maneuvering
- **Forward/Reverse:** Bow and stern arrays
- **Lateral:** Port and starboard arrays
- **Depth:** Bow and stern arrays (pitch control)
- **Rotation:** Asymmetric port/starboard firing
- **Station Keeping:** All arrays balanced

## Emergency Ascent
In emergency, all arrays fire downward simultaneously:
- Creates 2,000 N upward force
- Ascent rate: 10 m/s
- Duration: 30 seconds (150m from 500m depth)
- Ballast release for positive buoyancy backup

## Depth Control
- **Active:** Pitch control via bow/stern arrays
- **Passive:** Variable buoyancy chamber
- **Emergency:** Drop weights for instant positive buoyancy
- **Precision:** +/-0.5m depth hold at any depth
