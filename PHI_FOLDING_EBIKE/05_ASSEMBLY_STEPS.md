# PHI_FOLDING_EBIKE — Assembly Steps

> **Skill Level**: Intermediate (12-year-old can do it with adult supervision)
> **Time**: 6-8 hours
> **Tools Needed**: Allen key set, screwdrivers, wire strippers, spoke wrench, tire levers, multimeter

---

## Phase 1: Build the Wheels (1.5 hours)

### Step 1: Lace the Rear Wheel (Motor Wheel)

1. Take the 20" rear wheel rim (36-hole, motor-compatible)
2. Take the 350W hub motor — it has threaded holes for spokes
3. Insert spokes through motor flange holes (18 per side)
4. Lace spokes into rim using 3-cross pattern
5. Tighten spoke nipples evenly — wheel should be true (no wobble)
6. Use spoke wrench to adjust tension

**Tip**: Watch a YouTube video on "3-cross wheel lacing" before starting. It's easier than it sounds.

### Step 2: Install Tire and Tube

1. Install rim tape on both wheels
2. Insert one side of tire bead into rim
3. Insert inner tube (slightly inflated) into tire
4. Use tire levers to work the other tire bead onto the rim
5. Inflate to 40 PSI (2.8 bar)
6. Repeat for front wheel

### Step 3: Install Freewheel

1. Thread 7-speed freewheel onto rear hub (right side)
2. Hand-tighten, then use freewheel tool to secure
3. Verify it spins freely in one direction, locks in the other

---

## Phase 2: Assemble the Frame (1 hour)

### Step 4: Install Headset

1. Press headset cups into frame headtube (use headset press or block of wood + hammer)
2. Insert headset bearings (greased)
3. Insert fork steerer tube through headset
4. Thread top cap and adjust bearing preload

### Step 5: Install Stem and Handlebar

1. Slide stem onto fork steerer
2. Align stem with front wheel
3. Tighten stem clamp bolts evenly (5Nm)
4. Install handlebar in stem clamp
5. Center handlebar and tighten clamp
6. Install LCD display on left side of handlebar
7. Install thumb throttle on right side
8. Install brake levers (left = rear brake, right = front brake)
9. Install bell on left side

### Step 6: Install Seatpost and Saddle

1. Apply grease to seatpost
2. Insert seatpost into frame seat tube
3. Adjust to desired height
4. Tighten quick-release lever
5. Install saddle on seatpost
6. Adjust saddle angle (level) and tighten clamp

---

## Phase 3: Install Drivetrain (1 hour)

### Step 7: Install Crankset

1. Insert bottom bracket into frame (thread or press-fit)
2. Install drive-side crank arm onto bottom bracket spindle
3. Install non-drive-side crank arm
4. Tighten crank bolts to 40Nm
5. Install pedals (left pedal has reverse threads!)

### Step 8: Install Chain

1. Thread chain through rear derailleur
2. Wrap around front chainring and rear freewheel
3. Connect chain ends with quick-link
4. Adjust chain tension (should have 1" slack at midpoint)

### Step 9: Install Derailleur and Shifter

1. Bolt rear derailleur to frame dropout
2. Install shifter on right handlebar
3. Run shift cable from shifter to derailleur
4. Adjust derailleur limit screws:
   - H-screw: aligns with smallest cog
   - L-screw: aligns with largest cog
5. Adjust cable tension for smooth shifting

---

## Phase 4: Install Motor and Electronics (1.5 hours)

### Step 10: Install Rear Wheel (Motor)

1. Slide rear wheel into frame dropouts
2. Ensure motor wire exits on non-drive side
3. Tighten axle nuts evenly
4. Adjust brake alignment

### Step 11: Install Brakes

1. Mount V-brake arms on frame/fork brake bosses
2. Thread brake cables through arms
3. Adjust cable tension so pads sit 2mm from rim
4. Test brake lever feel — should engage halfway through pull
5. Adjust toe-in so pads hit rim evenly

### Step 12: Wire the Controller

1. Mount controller on frame downtube (zip ties + foam padding)
2. Connect battery to controller:
   - Controller BATTERY+ → XT60 Red (+)
   - Controller BATTERY- → XT60 Black (-)
3. Connect motor to controller:
   - Controller MOTOR U → Motor Blue wire
   - Controller MOTOR V → Motor Green wire
   - Controller MOTOR W → Motor Yellow wire
4. Connect hall sensors:
   - Controller HALL U/V/W → Motor hall sensor wires
5. Connect sensors:
   - Controller PAS → Cadence sensor signal
   - Controller THROTTLE → Thumb throttle signal
   - Controller BRAKE L → Left brake lever switch
   - Controller BRAKE R → Right brake lever switch
   - Controller SPEED → Speed sensor signal

### Step 13: Install Battery

1. Place battery in frame-mounted bag
2. Secure bag to downtube with Velcro straps
3. Connect battery to controller via XT60
4. Ensure no wires are near moving parts

### Step 14: Install Lights

1. Mount headlight on handlebar with bracket
2. Mount tail light on seatpost with bracket
3. Both are self-contained (USB rechargeable) — no wiring needed

---

## Phase 5: Final Assembly (30 minutes)

### Step 15: Cable Management

1. Secure all wires along frame with zip ties
2. Ensure no wires are near wheels, chain, or pedals
3. Leave slack at fold points (wire must flex when bike folds)
4. Trim excess zip ties

### Step 16: Test Functions

1. **DO NOT ride yet**
2. Turn on power switch
3. Verify LCD display shows battery level
4. Lift rear wheel off ground
5. Test throttle — wheel should spin
6. Test brake cutoffs — pulling either lever should stop motor
7. Test pedal assist — spin pedals, motor should assist
8. Test gear shifting — shift through all 7 gears
9. Test fold mechanism — fold and unfold bike

### Step 17: First Ride

1. Find a flat, empty parking lot
2. **Wear all safety gear**: helmet, knee pads
3. Unfold bike, lock all quick-releases
4. Start with pedal assist level 1
5. Practice pedaling with motor assist
6. Practice braking at low speed
7. Try thumb throttle at low speed
8. Ride for 15 minutes before venturing further

---

## Troubleshooting

| Problem | Solution |
|---------|----------|
| LCD won't turn on | Check battery connection, power switch |
| Motor doesn't spin | Check phase wire colors match controller |
| Motor stutters | Check hall sensor connections |
| Pedal assist not working | Check cadence sensor alignment, magnet spacing |
| Brakes rub rim | Adjust pad position, toe-in |
| Gears won't shift | Adjust derailleur limit screws, cable tension |
| Chain skips | Check chain length, derailleur alignment |
| Bike won't fold | Check fold joint lever, lubricate hinge |
