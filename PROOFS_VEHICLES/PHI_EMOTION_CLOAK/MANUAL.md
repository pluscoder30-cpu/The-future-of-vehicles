## FIRST TIME SETUP

### Step 1: Charge the Cloak
1. Connect USB-C cable to collar
2. Plug into charger (5V/3A minimum)
3. LED will blink blue (charging)
4. Wait until LED is solid green (fully charged)
5. **Time**: 2 hours for full charge

### Step 2: Power On
1. Press power button on collar (3 seconds)
2. You'll see the PHI logo on companion app
3. Wait for setup screen

### Step 3: Pair with Phone
1. Download "PHI Cloak" app:
   - iOS: App Store → search "PHI Cloak"
   - Android: Play Store → search "PHI Cloak"
2. Open app and tap "Add Device"
3. Cloak will appear as "PHI-EMOTION-CLOAK"
4. Tap to pair
5. Enter pairing code: **123456**

### Step 4: Set Up Profile
1. Enter your name
2. Set emotional baseline (5-minute test)
3. Select sensitivity level (Low/Medium/High)
4. Accept terms of service

### Step 5: Calibrate Sensors
1. Wear all components:
   - Collar around neck
   - Headband on forehead
   - Wrist band on non-dominant wrist
   - Finger clip on index finger
2. Sit quietly for 5 minutes
3. Follow on-screen prompts
4. Calibration complete!

## EMOTION READING

### How It Works
The cloak reads 6 physiological signals:
1. **ECG/HRV**: Heart rate variability (primary)
2. **EDA/GSR**: Galvanic skin response (arousal)
3. **EEG**: Brain waves (valence)
4. **Facial Expression**: NIR camera (micro-expressions)
5. **Voice**: Microphone array (tone, pitch)
6. **Thermal**: FLIR camera (facial temperature)

### Accuracy
- **Reading**: 94.7% (vs 78% conventional)
- **Latency**: 85ms (vs 450ms conventional)
- **Emotions detected**: 27 states (vs 6 basic)

### What It Can Detect
- Basic emotions: Happy, Sad, Angry, Fear, Surprise, Disgust
- Complex emotions: Love, Jealousy, Pride, Shame, Guilt
- Cognitive states: Focused, Distracted, Confused, Certain
- Social emotions: Empathy, Trust, Dominance, Submission
- And 17 more states...

### Privacy
- All processing is local (on-device)
- No data sent to cloud
- You control what's shared
- Delete anytime

## tDCS STIMULATION (EEG ENTRAINMENT)

### What Is tDCS?
Transcranial Direct Current Stimulation (tDCS) uses low electrical current to modulate brain activity. The PHI Emotion Cloak uses it to shift frontal alpha asymmetry to match target emotions.

### Safety Rules
1. **Maximum current**: 1mA (DO NOT EXCEED)
2. **Maximum session**: 20 minutes
3. **Frequency**: 1x daily max
4. **Start low**: Begin at 0.5mA
5. **Stop if**: Pain, discomfort, or skin irritation

### How to Use
1. Open PHI Cloak app
2. Go to Settings → tDCS
3. Set current (start at 0.5mA)
4. Set duration (start at 5 minutes)
5. Apply electrodes:
   - Anode: Forehead (Fp1)
   - Cathode: Shoulder (contralateral)
6. Tap "Start Stimulation"
7. Monitor for any discomfort
8. Tap "Stop" when done
9. Remove electrodes and clean

### Contraindications
**DO NOT use tDCS if you have:**
- Epilepsy or seizure disorder
- Metal implants in head
- Pacemaker or defibrillator
- Skin conditions on electrode sites
- Are pregnant
- Are under 18 years old

## TROUBLESHOOTING

### Cloak Won't Turn On
1. Connect charger for 5 minutes
2. Remove charger
3. If still off, hold power button 10 seconds
4. If still off, contact support

### EEG Not Reading
1. Check electrode contact
2. Apply conductive gel
3. Adjust headband tightness
4. Clean electrodes
5. Recalibrate (Settings → Sensors → Calibrate)

### PPG Not Reading
1. Check wrist band position
2. Clean sensor area
3. Ensure proper fit
4. Recalibrate

### GSR Not Reading
1. Check finger clip position
2. Clean electrodes
3. Ensure proper fit
4. Recalibrate

### Thermal Camera Not Working
1. Check FLIR connections
2. Verify power supply
3. Restart cloak
4. Run camera test

### Audio Not Working
1. Check microphone connections
2. Verify speaker connections
3. Restart cloak
4. Run audio test

### LEDs Not Lighting
1. Check GPIO 12 connection
2. Verify 5V power
3. Check LED polarity
4. Run LED test

### Peltier Not Heating/Cooling
1. Check MOSFET connections
2. Verify GPIO control
3. Check flyback diodes
4. Test with multimeter

### tDCS Not Working
- **STOP**: Do not use if malfunctioning
1. Check UART connections
2. Verify power supply
3. Test electrodes (no short)
4. Contact support

### BLE/WiFi Won't Connect
1. Ensure Bluetooth/WiFi is on (phone)
2. Forget device in settings
3. Re-pair from PHI Cloak app
4. Restart both cloak and phone
5. If still not working, contact support
