# PHI BIO SKIN WATCH — README

## Quick Start
1. Remove from packaging
2. Charge battery (20 min on phi-harmonic dock)
3. Download app and pair via Bluetooth
4. Run initial calibration (5 minutes)
5. Wear and enjoy (self-cleaning, self-healing)
6. Raise wrist to see time
7. Double-tap to activate display
8. Never clean (self-cleaning surface)

## Specifications at a Glance
- **MSRP:** $100
- **Battery:** FPB-5 (5 kWh, $100)
- **Weight:** 45g
- **Display:** 1.2" AMOLED (hidden when off)
- **Battery Life:** 365 days (time only)
- **Charge Time:** 20 min (phi-harmonic) / 4 hrs (Qi2)
- **Waterproof:** IP68 (50m)
- **Self-Cleaning:** Yes (continuous)
- **Self-Healing:** Yes (2-8 hours)
