# PHI BIO SKIN WATCH — Structural Design

## Watch Architecture
The Bio Skin Watch uses a single-piece bio-skin construction where the watch face and band are one continuous material.

### Bio-Skin Specifications
| Parameter | Value |
|-----------|-------|
| Material | Living polymer composite |
| Thickness | 2.5mm (face), 1.5mm (band) |
| Weight | 45g (total) |
| Flexibility | 360-degree bend radius |
| Water Resistance | IP68 (swimmable to 50m) |
| Operating Temp | -20C to +60C |
| Scratch Resistance | Self-healing (2-8 hours) |

### Watch Face
| Parameter | Value |
|-----------|-------|
| Diameter | 38mm |
| Thickness | 8mm |
| Display | 1.2" AMOLED (hidden when off) |
| Resolution | 390 x 390 pixels |
| Brightness | 0-1000 nits (auto) |
| Glass | Sapphire crystal (phi-coated) |

### Band
| Parameter | Value |
|-----------|-------|
| Material | Same bio-skin as face |
| Width | 20mm |
| Length | Adjustable (140-210mm) |
| Closure | Magnetic phi-lock |
| Comfort | Medical-grade hypoallergenic |

## Phi-Spiral Surface Pattern
The watch face features a visible phi-spiral pattern:
- **Aesthetic:** Golden-ratio spirals etched into bio-skin
- **Functional:** Channels for self-cleaning field
- **Hidden:** Display emerges from between spirals
- **Default:** Matte black with golden phi-trace shimmer

## Display Integration
The AMOLED display is embedded within the bio-skin:
- **Hidden State:** Surface appears solid black
- **Active State:** Display illuminates through bio-skin
- **Transition:** Smooth fade-in/fade-out
- **Always-On Option:** Dim time display

## Sensor Locations
- **Heart Rate:** Bottom of watch (wrist contact)
- **SpO2:** Side of watch (finger contact option)
- **Temperature:** Inner surface (skin contact)
- **Accelerometer:** Center of watch
- **Gyroscope:** Center of watch
