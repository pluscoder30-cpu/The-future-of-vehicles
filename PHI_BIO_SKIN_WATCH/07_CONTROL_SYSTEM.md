# PHI BIO SKIN WATCH — Control System

## Control Interface
The Bio Skin Watch uses minimal physical controls — the primary interface is gestures and the hidden display.

## Physical Controls

### Crown Button
- **Location:** Right side (3 o'clock)
- **Function:** Power on/off, menu navigation
- **Operation:** Single press = wake/display, Rotate = scroll, Hold = settings

### Side Button
- **Location:** Right side (2 o'clock)
- **Function:** Quick actions
- **Operation:** Single press = recent apps, Double press = payment, Hold = emergency

## Gesture Controls
- **Raise to Wake:** Tilt wrist to see time
- **Double Tap:** Activate display
- **Swipe Up/Down:** Scroll notifications
- **Swipe Left/Right:** Switch watch faces
- **Cover Display:** Turn off display

## Display Modes
| Mode | Description | Display |
|------|-------------|---------|
| Time | Clock face | Always-on (dim) |
| Notifications | Incoming alerts | On-demand |
| Health | Heart rate, SpO2 | On-demand |
| Weather | Current conditions | On-demand |
| Payment | Contactless pay | On-demand |
| Custom | User-configured | On-demand |

## Watch Faces
- **Default:** Phi-spiral with golden hands
- **Minimal:** Simple digital time
- **Health:** Heart rate graph
- **Analog:** Classic watch face
- **Custom:** Upload your own image
- **Dynamic:** Changes with emotion (requires Emotion Cloak pairing)

## Mobile App
- **Setup:** Pairing, calibration, preferences
- **Health Dashboard:** All health metrics
- **Watch Faces:** Browse and install
- **Notifications:** Manage app alerts
- **Payment:** Set up contactless pay
- **Find My Watch:** Locate via Bluetooth
- **Firmware Updates:** Over-the-air

## Voice Control
- "Hey Phi" activates voice assistant
- "What time is it?" — speaks time
- "Start workout" — begins exercise tracking
- "Call [name]" — initiates phone call
- "Show heart rate" — displays health data
