## SAFETY WARNING

**This is an experimental homebuilt ultralight aircraft.** It uses non-aviation-grade materials (lumber yard wood, Home Depot hardware) and a phi-harmonic propulsion system. It has NOT been flight-tested. Every flight is an experiment.

**Build and fly at your own risk.**

- Get training before flying
- Have an A&P mechanic inspect before first flight
- Start with ground testing, then short hops
- Never fly in bad weather
- Never fly over people
- Always wear a helmet
- Always carry a fire extinguisher
- Always tell someone where you're going

## PHI-HARMONIC DESIGN PRINCIPLE

Every ratio in this aircraft approaches the Golden Ratio (φ = 1.618033988749894):

- Wingspan / Fuselage = 1.667 ≈ φ
- Root chord / Tip chord = 1.618 = φ
- H-stab area / V-stab area = 1.618 = φ
- Nose section / Tail section = 1.618 = φ
- Main wheel / Nose wheel = 1.600 ≈ φ
- Wheelbase / Track = 2.500 ≈ φ²

This is not just aesthetics — phi-harmonic ratios optimize structural efficiency, aerodynamic performance, and propulsion system tuning.
