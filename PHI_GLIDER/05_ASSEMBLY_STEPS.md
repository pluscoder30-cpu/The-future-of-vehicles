# PHI_GLIDER — Assembly Steps

> **Skill Level**: Intermediate (requires basic aviation knowledge)
> **Time**: 20-30 hours over several weekends
> **Tools Needed**: Rivet gun, drill, wrenches, wire strippers, multimeter, sewing kit

> ⚠️ **WARNING: This is an aircraft. Improper assembly can result in death. Take hang gliding lessons before attempting to fly.**

---

## Phase 1: Build the Wing Frame (8 hours)

### Step 1: Cut Aluminum Tubing

1. Cut 4× main spars (25mm × 2.5m each)
2. Cut 6× struts (20mm × 2m each)
3. Cut 8× ribs (15mm × 1.5m each)
4. Deburr all cut ends
5. Mark all pieces with tape labels

### Step 2: Assemble Wing Skeleton

1. Lay out 2 main spars parallel, 2m apart
2. Connect with cross-braces at 1m intervals using rivets
3. Attach struts at 45° angles for diagonal bracing
4. Attach ribs at 30cm intervals along leading edge
5. **Check all angles with protractor** — must be 90° ± 1°

### Step 3: Install Motor Mounts

1. Mark motor mount positions on wing (2m from center, each side)
2. Drill 4× M6 holes at each position
3. Bolt motor mounts to wing frame
4. Verify alignment — motors must point straight ahead

---

## Phase 2: Cover the Wing (6 hours)

### Step 4: Sew Wing Cover

1. Lay Dacron sailcloth over wing frame
2. Mark cutting lines 5cm outside frame edges
3. Cut with sharp scissors
4. Sew reinforcement strips along leading edge
5. Sew pocket for wing tips
6. Test fit on frame

### Step 5: Attach Wing Cover

1. Drape cover over wing frame
2. Start at center, work outward
3. Use zip ties through grommets to secure
4. Ensure cover is taut — no wrinkles
5. Sew closed all openings

---

## Phase 3: Install Motors (4 hours)

### Step 6: Prepare Ducted Fans

1. Assemble duct shrouds
2. Mount motors in ducts
3. Attach propellers (ensure correct rotation direction)
4. Balance propellers (use balancing stand)
5. Test motor spin (no power yet)

### Step 7: Mount Motors on Wing

1. Bolt ducted fans to motor mounts
2. Ensure motors are level and aligned
3. Route motor wires through wing
4. Secure wires with zip ties every 20cm
5. Connect wires to controller

---

## Phase 4: Build Control Frame (4 hours)

### Step 8: Assemble Control Frame

1. Cut aluminum tubing for triangular frame
2. Rivet joints together
3. Install carabiner attachment points
4. Install control bar
5. Mount throttle and kill switch on control bar

### Step 9: Install Pilot Harness

1. Attach webbing to control frame
2. Install quick-release buckles
3. Adjust harness for pilot size
4. Test harness strength (hang with 100kg weight)

---

## Phase 5: Install Electronics (4 hours)

### Step 10: Mount Battery

1. Install battery bracket on control frame
2. Mount battery pack
3. Secure with Velcro straps
4. Route battery wire to controller

### Step 11: Mount Controller

1. Mount controller on control frame
2. Connect motor wires (Left: A, B, C; Right: A, B, C)
3. Connect throttle wire
4. Connect kill switch wire
5. Connect battery monitor wire

### Step 12: Final Wiring Check

1. **Double-check every connection** with multimeter
2. Verify no bare wires touching frame
3. Verify all connectors are fully seated
4. Test kill switch function (lanyard pull = motor cut)
5. Test throttle function (pull = motor spin up)

---

## Phase 6: Testing (4 hours)

### Step 13: Ground Tests

1. **Secure glider to ground** (tiedown straps)
2. Power up system
3. Test throttle response
4. Test kill switch
5. Run motors at full power for 30 seconds
6. Check for vibration, heat, noise
7. **If anything sounds wrong, STOP and check**

### Step 14: Taxi Tests

1. Find flat, open area (minimum 100m × 50m)
2. **Do NOT attempt takeoff yet**
3. Start motor at low power
4. Let glider roll forward (you hold it back)
5. Verify steering response
6. Verify brakes (if installed)
7. Gradually increase power

### Step 15: Flight Training

> ⚠️ **DO NOT FLY WITHOUT TRAINING**
> 
> Before attempting flight:
> 1. Take hang gliding lessons (minimum 10 hours ground school)
> 2. Practice with certified instructor
> 3. Complete 10 training flights with instructor
> 4. Get medical clearance
> 5. Check local aviation regulations
> 6. Get insurance

## Troubleshooting

| Problem | Solution |
|---------|----------|
| Motors don't spin | Check battery, fuse, wiring |
| One motor spins faster | Rebalance propellers |
| Excessive vibration | Check motor alignment |
| Kill switch doesn't work | Check lanyard, reed switch |
| Throttle doesn't respond | Check potentiometer, wiring |
| Wing flexes too much | Add more cross-braces |
| Cover sags | Tighten zip ties |
