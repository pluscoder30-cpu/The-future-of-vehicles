## Manufacturing Steps

### 1. Hull Fabrication (Day 1-10)
- CNC mold creation for manta-ray form
- Lay carbon/graphene composite hull
- Cure in autoclave at 180C / 8 bar
- Install phi-spiral reinforcement ribs
- Apply marine anti-fouling coating (phi-harmonic)

### 2. Field Array Assembly (Day 5-8)
- Wind copper wire on phi-geometry mandrels
- Assemble 4 arrays in phi-helical jig
- Connect to drag reduction synchronizer
- Test resonance frequency (target 1.618 MHz)

### 3. Systems Integration (Day 8-12)
- Install battery in marine-rated housing
- Mount navigation computer and dashboard
- Wire power distribution harness
- Install thrusters and control surfaces
- Connect plumbing (freshwater, waste)

### 4. Interior Assembly (Day 12-15)
- Install seats, galley, head
- Mount viewports (triple-sealed)
- Connect entertainment system
- Install safety equipment
- Finish deck and trim

### 5. Final Assembly (Day 15-16)
- Install deck and bimini
- Connect all wiring and plumbing
- Ground tackle installation
- Full system integration test

### 6. Quality Assurance (Day 16-21)
- Water tank test (leak check)
- Field skimmer function test
- Navigation system verification
- Communication test
- 48-hour sea trial
- Subsurface test (50m depth)
- Emergency system test
- Passenger comfort test
