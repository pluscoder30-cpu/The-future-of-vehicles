# PHI OCEAN VEHICLE — Maintenance Guide

## Maintenance Philosophy
The Ocean Vehicle operates in saltwater, the most corrosive natural environment. The phi-harmonic drag reduction field eliminates biofouling, and the solid-state systems minimize mechanical wear.

## Maintenance Schedule

### Pre-Departure (Before Each Trip, 10 min)
- [ ] Visual hull inspection (above and below waterline)
- [ ] Field skimmer status check
- [ ] Battery level check
- [ ] Navigation system test
- [ ] Communication test (VHF radio)
- [ ] Safety equipment check
- [ ] Bilge pump test
- [ ] Weather check

### After Each Trip
- [ ] Rinse hull with fresh water
- [ ] Inspect hull for damage
- [ ] Check anodes (phi-harmonic sacrificial)
- [ ] Log trip (distance, battery usage)

### Monthly (4 hours)
- [ ] Full field coil resonance test
- [ ] Hull inspection (above and below)
- [ ] Navigation calibration
- [ ] Communication system test
- [ ] Plumbing system check
- [ ] Electrical system inspection
- [ ] Battery full cycle test
- [ ] Safety equipment inventory

### Annual (16 hours)
- [ ] Professional inspection at marine service center
- [ ] Hull ultrasound thickness measurement
- [ ] Field coil deep diagnostic
- [ ] Navigation system recertification
- [ ] Plumbing system overhaul
- [ ] Electrical system insulation test
- [ ] Safety equipment replacement
- [ ] Full system recertification
- [ ] Sea trial (24 hours)

### Every 5 Years
- [ ] Complete hull re-certification
- [ ] Field coil refurbishment ($400)
- [ ] Viewport replacement (if needed)
- [ ] Complete safety equipment overhaul
- [ ] Electrical system rebuild

## Storage
- Rinse thoroughly with fresh water after saltwater use
- Store on boat trailer or in dry stack
- Battery: store at 50% charge
- Hull: Cover with breathable canvas
- Viewports: Protect from UV and scratches
- Field system: Run monthly test cycle
