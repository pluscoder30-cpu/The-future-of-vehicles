# PHI OCEAN VEHICLE — Structural Design

## Hull Architecture
The Ocean Vehicle uses a carbon fiber / graphene composite hull designed for both surface and subsurface operations. The hull incorporates phi-spiral reinforcement ribs that distribute hydrodynamic loads evenly.

### Hull Specifications
| Parameter | Value |
|-----------|-------|
| Material | Carbon fiber / graphene composite |
| Thickness | 20mm (pressure hull) |
| Weight | 120 kg (hull only) |
| Maximum Depth | 50m (subsurface mode) |
| Surface Rating | Unlimited |
| Impact Rating | 25g |
| Fatigue Life | 100,000 cycles |

### Exterior
| Parameter | Value |
|-----------|-------|
| Length | 6,000 mm |
| Width | 2,500 mm |
| Height | 1,200 mm (above waterline) |
| Draft | 800 mm |
| Dry Weight | 350 kg |
| Displacement | 500 kg (in water) |
| Passenger Capacity | 6 |

## Viewports
- **Type:** Acrylic panoramic panels
- **Size:** 4x 600mm x 400mm
- **Thickness:** 40mm
- **Visibility:** 270 degrees (wrap-around)
- **Defogging:** Phi-harmonic thermal coating

## Deck
- **Material:** Teak-patterned graphene composite
- **Features:** Integrated solar panel (1 kW)
- **Seating:** 6-person outdoor lounge
- **Bimini:** Retractable shade canopy

## Interior
- **Salon:** 4-person dining/conference
- **Galley:** Compact kitchen (induction, sink)
- **Head:** Marine toilet with holding tank
- **Berth:** 2-person sleeping area
- **Storage:** Under-seat compartments

## Structural Safety
- Watertight bulkheads (3 compartments)
- Automatic bilge pumps (2x redundant)
- Collision bulkhead at bow
- Emergency flotation (foam-filled compartments)
- Ground tackle (anchor + chain)
