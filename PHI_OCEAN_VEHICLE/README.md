# PHI OCEAN VEHICLE — README

## Quick Start
1. Launch vehicle into water (ramp or crane)
2. Power on (hold button 3 sec)
3. Wait for self-test (3 min)
4. Board from stern or side
5. Secure harness at chosen seat
6. Engage field skimmer (toggle switch)
7. Use helm and throttle to navigate
8. For subsurface: Use depth joystick
9. Emergency: Deploy EPIRB + VHF Mayday

## Specifications at a Glance
- **MSRP:** $4,000

- **Range:** 2,000 km (cruising)
- **Charge Time:** 30 min (phi-harmonic) / 4 hrs (standard)
- **Passengers:** 6
- **Max Depth:** 50m (subsurface)

## Safety Warnings
- Always wear life jacket in rough weather
- Never exceed 50m depth in subsurface mode
- Maintain 30% battery minimum for return trip
- Check weather before every departure
- Carry all required safety equipment
- File float plan with someone ashore
