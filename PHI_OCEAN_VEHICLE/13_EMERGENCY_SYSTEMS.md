# PHI OCEAN VEHICLE — Emergency Systems

## Emergency Priority Matrix
| Priority | Condition | Response |
|----------|-----------|----------|
| 1 - Critical | Hull breach / sinking | Emergency flotation + distress |
| 2 - High | Power failure | Deploy drogue, activate EPIRB |
| 3 - Medium | Field skimmer failure | Reduce speed, return to port |
| 4 - Low | Battery <15% | Head to nearest port |
| 5 - Info | Weather warning | Navigate to shelter |

## Capsize Response
1. Vehicle self-rights (low center of gravity)
2. All compartments remain watertight
3. Air supply maintained in cabin
4. EPIRB auto-deploys
5. VHF distress call auto-transmits
6. Survival kit accessible from seats
7. Await rescue (30+ minutes air supply)

## Hull Breach Response
1. Breach sensors detect location
2. Watertight bulkheads seal automatically
3. Bilge pumps activate (2x redundant)
4. Emergency flotation deployed
5. VHF distress call transmitted
6. EPIRB activated
7. Prepare to abandon vessel if needed

## Man Overboard Response
1. Weight sensors detect person leaving
2. Alarm sounds, GPS marks position
3. Vehicle circles at safe distance
4. Recovery ladder deploys at stern
5. Spotlights illuminate (night)
6. If >5 minutes: EPIRB deploys for person

## Emergency Flotation
- Foam-filled compartments (automatic)
- Inflatable buoyancy bags (manual activation)
- Life jackets for all 6 passengers
- Life raft for 6 (manual deployment)
- EPIRB with GPS (406 MHz)

## Communication in Emergency
1. **VHF Radio:** Mayday on Channel 16
2. **EPIRB:** 406 MHz distress beacon (GPS encoded)
3. **AIS:** Emergency signal broadcast
4. **Flares:** Visual distress signals (included)
5. **Mirror:** Signal mirror for aircraft
6. **Phone:** Bluetooth notification (if near shore)

## Post-Emergency
- System enters lockout mode
- Full inspection required before next use
- Event data recorder preserves last 120 minutes
- Report filed via mobile app
- Insurance notification triggered
- Emergency services contacted
