# PHI FTL FREIGHT — ASSEMBLY GUIDE

## Step-by-Step Build Instructions

---

## PHASE 1: CHASSIS ASSEMBLY (60-80 hours)

### Step 1: Frame Preparation
```
1. Lay ultra-heavy ladder frame on flat surface
2. Verify phi-spaced cross members (618mm)
3. Weld cross members to main rails
4. Grind welds smooth
5. Apply rust-preventive coating
```

### Step 2: Suspension Mounting
```
1. Install front double-wishbone mounting points
2. Install rear leaf spring hangers
3. Mount front coilovers (phi-tuned)
4. Mount rear leaf springs (11-leaf packs)
5. Install fifth wheel coupling
```

---

## PHASE 2: FPB-100 BATTERY INSTALLATION (25-35 hours)

### Step 3: Battery Connection
```
1. Mount FPB-100 in cradle
2. Connect HV main cables (70mm² orange)
3. Install HV contactor (600A)
4. Connect BMS CAN bus
5. Verify all connections
6. DO NOT ENERGIZE until Phase 4 complete
```

---

## PHASE 3: WARP FIELD SYSTEM (35-45 hours)

### Step 4: Warp Coil Installation
```
1. Mount 10 warp coils in phi-decagon pattern
   ┌───────────────────────────────┐
   │     C1 ─────────── C2        │
   │    ╱                   ╲      │
   │  C10                    C3    │
   │  │                       │    │
   │  C9                      C4    │
   │  │       ●               │    │
   │  C8                      C5    │
   │  │                       │    │
   │  C7                      C6    │
   │    ╲                   ╱      │
   │     C7 ─────────── C6        │
   └───────────────────────────────┘
   
2. Each coil: 432μH, rated 300A peak
3. Connect coil drivers to warp controller
4. Install field emitter nodes (12× around perimeter)
5. Mount resonance stabilizer
```

---

## PHASE 4: CABIN & TRAILER (35-45 hours)

### Step 5: Cabin Assembly
```
1. Mount cab onto frame
2. Install windshield and side windows
3. Mount steering column and wheel
4. Install pedal assembly
5. Mount seats
6. Route all wiring through firewall
```

### Step 6: Trailer
```
1. Install trailer subframe
2. Mount 6mm steel floor
3. Attach 5mm aluminum side walls
4. Install roll-up rear doors
5. Add cargo tie-downs (30×)
6. Install hydraulic loading ramp
```
