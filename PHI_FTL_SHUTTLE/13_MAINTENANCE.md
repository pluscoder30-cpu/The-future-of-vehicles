# Maintenance — Warp Coil Inspection, Battery Service, and Bubble Calibration

## 1. Maintenance Philosophy

The FTL shuttle requires specialized maintenance due to its warp technology. Maintenance is organized into three tiers:

| Tier | Scope | Performed by | Interval |
|------|-------|-------------|----------|
| Tier 1 | Pre-flight, post-flight checks | Pilot / crew | Every flight |
| Tier 2 | Scheduled maintenance | PHI technician | Per schedule |
| Tier 3 | Major overhaul | PHI engineering | Per schedule |

## 2. Tier 1 — Pre-Flight / Post-Flight Checks

### 2.1 Pre-Flight Checklist

```
Pre-flight checklist (20 minutes):
  □ Visual inspection (hull, windows, exits)
  □ Warp coil status (temperature, integrity)
  □ Battery status (charge level, temperature)
  □ Navigation system (GPS lock, star catalog)
  □ Communication system (radio check, FTL-com)
  □ Life support (oxygen, temperature, pressure)
  □ Safety systems (warp abort, emergency beacon)
  □ Warp cocoon (deployment test)
  □ Payload (clamped, secure)
  □ Cabin (clean, clear, exits unobstructed)
  □ Warp radar scan (target location)
  □ Warp clearance (ground control)
```

### 2.2 Post-Flight Checklist

```
Post-flight checklist (15 minutes):
  □ Warp status (completed, no anomalies)
  □ Warp coil status (temperature, integrity)
  □ Battery status (charge level, temperature)
  □ Navigation system (arrival accuracy)
  □ Communication system (log transmitted)
  □ Life support (consumables level)
  □ Safety systems (status OK)
  □ Warp cocoon (retracted, clean)
  □ Payload (unloaded, condition OK)
  □ Cabin (clean, clear, exits unobstructed)
  □ Data log (downloaded, reviewed)
  □ Maintenance log (updated)
```

## 5. Bubble Calibration

### 5.1 Purpose

Bubble calibration ensures that the warp coils generate warp bubbles of the correct size, shape, and velocity. Calibration is required:
- After every 5 light-years
- After any warp coil replacement
- After any structural modification
- After any navigation system change
- After any transportation of the vehicle

### 5.2 Calibration Procedure

```
Bubble calibration procedure (3 hours):
  1. Set up calibration targets (3 at known star positions)
  2. Power up warp coils to idle
  3. Run calibration sequence (automatic):
     a. Generate warp bubble at vehicle center
     b. Measure bubble radius (±0.01 m)
     c. Measure bubble wall thickness (±0.001 m)
     d. Measure bubble velocity (±0.01c)
     e. Adjust coil phases to correct errors
     f. Repeat until all parameters within tolerance
  4. Generate warp bubble at each calibration target
  5. Measure bubble position at target (±0.001 LY)
  6. Measure bubble velocity at target (±0.1c)
  7. Adjust coil phases to correct errors
  8. Verify warp bubble formation at each target
  9. Log calibration data
  10. Generate calibration certificate
```

### 5.3 Calibration Tolerances

| Parameter | Tolerance | Consequence of exceedance |
|-----------|-----------|--------------------------|
| Bubble radius | ±0.01 m | Warp instability |
| Bubble wall thickness | ±0.001 m | Warp instability |
| Bubble velocity | ±0.01c | Navigation error |
| Bubble position | ±0.001 LY | Navigation error |
| Bubble field amplitude | ±1% | Warp instability |
| Bubble frequency | ±0.001% | Warp coherence loss |

### 5.4 Calibration Equipment

| Equipment | Purpose | Calibration interval |
|-----------|---------|---------------------|
| PHI calibration tool | Warp bubble measurement | Annual |
| Star reference receiver | Position reference | Annual |
| Warp field probe | Field strength measurement | Annual |

| Metric coherence sensor | Metric coherence measurement | Annual |

## 7. Warp Coil Inspection

### 7.1 Visual Inspection

```
Warp coil visual inspection:
  □ Coil former (cracks, chips, discoloration)
  □ Coil windings (loose wires, corrosion)
  □ Coil connections (tight, clean, corrosion-free)
  □ Coil mount (tight, aligned, no damage)
  □ Coil cooling (lines clear, no leaks)
  □ Coil field probes (clean, aligned)
```

### 7.2 Electrical Inspection

```
Warp coil electrical inspection:
  □ Coil resistance (< 0.05 Ω)
  □ Coil inductance (4.8 ± 0.1 mH)
  □ Coil resonant frequency (80.9 ± 0.3 kHz)
  □ Coil current capacity (8,000 A)
  □ Coil insulation resistance (> 200 MΩ)
  □ Coil quench detection (functional)
```

### 7.3 Superconductor Inspection

```
Warp coil superconductor inspection:
  □ YBCO tape integrity (visual)
  □ YBCO critical current (> 800 A at 77K)
  □ YBCO cooling (liquid nitrogen level, flow)
  □ YBCO joints (resistance < 0.5 nΩ)
  □ YBCO insulation (integrity, no damage)
```

## 8. Documentation

### 8.1 Maintenance Log

All maintenance must be documented in the maintenance log:

```
Maintenance log entry format:
  Date: YYYY-MM-DD
  Technician: [name]
  Vehicle: [call sign]
  Light-year count: [number]
  Tier: [1/2/3]
  Tasks performed: [list]
  Parts replaced: [list]
  Anomalies found: [list]
  Corrective actions: [list]
  Next maintenance: [date/light-year count]
  Signature: [technician]
```

### 8.2 Maintenance Records

Maintenance records must be retained for:
- Life of the vehicle + 10 years
- All Tier 2 and Tier 3 maintenance
- All warp abort events
- All emergency events
- All modifications
