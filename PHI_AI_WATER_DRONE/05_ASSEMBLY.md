# PHI AI WATER DRONE — ASSEMBLY GUIDE

## Step-by-Step Build Instructions (AI-Enhanced)

---

## PHASE 1: FRAME ASSEMBLY (8-10 hours)

### Step 1: Print Frame Parts

Print all frame components including filtration mount and AI bracket.
- Material: PLA 1.75mm
- Infill: 40% gyroid
- Print Time: ~16 hours

### Step 2: Assemble Frame

1. Connect arms to center body
2. Install motor mounts
3. Mount filtration system bracket
4. Mount AI processor bracket

---

## PHASE 2: FILTRATION SYSTEM (4-6 hours)

### Step 3: Install Filtration

```
FILTRATION INSTALLATION:
═══════════════════════════════════════════════════════════════

  1. Mount water pump in center body
  2. Install filter housings (3 stages)
  3. Connect intake hose (bottom mount)
  4. Connect output hose (clean water outlet)
  5. Test pump flow rate (should be 1L/min)
  6. Check for leaks
```

---

## PHASE 3: ELECTRONICS (12-14 hours)

### Step 4: Wire Water Sensors

Connect pH, turbidity, TDS, and temperature sensors to Arduino analog pins.

### Step 5: Install AI Processor

```
AI PROCESSOR INSTALLATION:
═══════════════════════════════════════════════════════════════

  1. Mount Raspberry Pi Zero 2W
  2. Connect serial to Arduino
  3. Mount camera for water surface imaging
  4. Flash AI contamination mapping model
  5. Test AI inference with sensor data
```

---

## PHASE 4: TESTING (4-6 hours)

### AI System Tests

```
AI WATER SYSTEM TESTS:
═══════════════════════════════════════════════════════════════

  □ pH sensor reads correctly in test solution
  □ Turbidity sensor detects particles
  □ TDS sensor reads dissolved solids
  □ AI contamination map generates correctly
  □ AI classifies pollutant type
  □ AI optimizes cleaning path
  □ Filtration system processes water
  □ Multi-drone communication works
```
