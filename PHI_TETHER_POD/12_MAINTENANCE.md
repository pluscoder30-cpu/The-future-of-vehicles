# PHI TETHER POD — Maintenance Guide

## Maintenance Philosophy
The Tether Pod uses solid-state phi-harmonic systems with no lubricants, no filters, and no consumable fluids. Maintenance is primarily inspection-based.

## Maintenance Schedule

### Pre-Flight (Before Each Use, 2 min)
- [ ] Visual inspection of shell for cracks or damage
- [ ] Tether spool deployment test (full extend/retract)
- [ ] Battery level check (must be >20% for flight)
- [ ] Anchor stake inspection (no bends or corrosion)
- [ ] Touch ring responsiveness test

### Monthly (30 min)
- [ ] Full tether inspection (run fingers along length, feel for kinks)
- [ ] Phi-harmonic resonance test (Q factor measurement)
- [ ] Battery charge cycle (full discharge, full charge)
- [ ] Control unit firmware check (update if available)
- [ ] Harness inspection (webbing, buckles, stitching)

### Annual (2 hours)
- [ ] Professional inspection at authorized service center
- [ ] Load test to 150% rated capacity
- [ ] Field coherence measurement
- [ ] Battery health diagnostic
- [ ] Shell integrity ultrasound scan
- [ ] Anchor stake torque test

### Every 5 Years
- [ ] Complete tether replacement ($25)
- [ ] Full system recertification
- [ ] Firmware major version update
- [ ] Structural inspection for fatigue

## Diagnostic Mode
Hold the touch ring for 5 seconds to enter diagnostic mode:
- **Green ring:** All systems nominal
- **Yellow ring:** Maintenance due soon
- **Red ring:** Immediate attention required
- **Blinking:** Error code displayed (consult manual)

## Storage
- Store in carry case in cool, dry location
- Battery: store at 50% charge for long-term
- Tether: retract fully before storage
- Temperature: -20C to +50C storage range
