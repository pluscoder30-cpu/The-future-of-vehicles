## Manufacturing Steps

### 1. Shell Fabrication (Day 1-2)
- CNC-cut graphene composite sheets
- Thermoform in phi-spiral mold at 180C
- Trim and drill mounting points
- Apply UV-resistant clear coat

### 2. Tether Assembly (Day 1)
- Extrude CNT/graphene composite filament (0.8mm)
- Embed piezoelectric emitters at 1m intervals
- Wind onto titanium spool with tension control
- Test phi-harmonic resonance (target Q>80)

### 3. Electronics Integration (Day 3)
- Assemble control PCB with flight computer
- Install touch ring and OLED display
- Wire power distribution harness
- Flash firmware and run self-test

### 4. Battery Integration (Day 3)
- Mount FPB-5 in dedicated bay
- Connect power bus with phi-harmonic filter
- Verify charge/discharge cycle
- Test emergency reserve activation

### 5. Final Assembly (Day 4)
- Install seat and harness system
- Mount anchor stake to tether
- Connect all wiring
- Full system integration test

### 6. Quality Assurance (Day 4-5)
- Load test to 200% rated capacity
- 24-hour field coherence stability test
- Drop test from 2m onto concrete
- Water immersion test (IP67)
- 1-hour continuous flight test
