# PHI TETHER POD — Quick Start Guide

## What You Built

A portable personal suspension pod. You can hang in mid-air up to 10m high, powered by a 12V battery. It folds into a carry case and deploys in 30 seconds.

**Cost:** ~$715 | **Build Time:** 6-8 hours | **Weight:** 8.2 kg total

---

## Before You Suspend

### Safety (NON-NEGOTIABLE)

1. **NEVER SUSPEND ALONE** — always have a ground person
2. Harness fully buckled — all 4 clips
3. Helmet on, chin strap tight
4. Tether inspected — no fraying, no knots
5. Emergency descent device accessible
6. Ground anchors secure
7. Wind <20 km/h
8. No overhead wires within 20m

### Pre-Use Checklist

- [ ] Tether inspected (no fraying)
- [ ] Harness buckled (4 clips: chest, 2x lap, leg)
- [ ] Kill switch tested
- [ ] Remote control works
- [ ] Height sensor reads correctly
- [ ] Battery >80%
- [ ] Emergency descent device accessible
- [ ] Radio works (both units)
- [ ] Wind <20 km/h
- [ ] No overhead wires
- [ ] Ground person briefed

## Deployment Sequence

### From Carry to Suspended (30 seconds)

1. **Find location** — flat ground, no obstacles, no wires
2. **Set ground anchors** — drive 2 anchors 30cm deep
3. **Attach guy lines** — clip to pod frame, tension to stakes
4. **Unfold pod** — extend frame, lock pins
5. **Wind tether** — thread through winder, attach to anchor
6. **Sit in pod** — buckle all 4 harness clips
7. **Attach tether** — quick-release hook to D-ring
8. **Power on:**
   - SW1 ON — winch ready
   - SW2 ON — instruments + light
9. **Attach kill switch** to wrist
10. **Tell ground person** — "Ready to lift!"
11. **Press UP on remote** — you go up!

## Operating

### Controls

| Control | Function |
|---------|----------|
| Remote UP button | Ascend (winch pulls in) |
| Remote DOWN button | Descend (winch lets out) |
| Remote CENTER | Stop (auto-brake holds) |
| SW1 | Winch ON/OFF |
| SW2 | Instruments + light ON/OFF |
| Kill switch | Emergency stop |

### Height Management

- **0-3m:** Safe zone, easy to reach ground
- **3-7m:** Working zone, good vantage point
- **7-10m:** Maximum, limit exposure time
- **Emergency:** Pull EDD pin = controlled descent

### Wind Rules

| Wind Speed | Action |
|------------|--------|
| 0-10 km/h | All good |
| 10-20 km/h | Caution, descend to 3m |
| 20+ km/h | DESCEND IMMEDIATELY |

## Emergency Procedures

### Winch Failure
1. Press kill switch (motor stops)
2. Auto-brake holds position
3. Pull EDD pin — controlled descent
4. Land, unbuckle, walk away

### Tether Snaps
1. Extremely unlikely (Dyneema rated 2200kg)
2. If it happens: grab EDD pin
3. Pull pin — controlled descent
4. Land safely

### Strong Gust
1. Press DOWN on remote
2. Descend to ground level
3. Wait for wind to die
4. Or: release tether, walk pod to shelter

### Electrical Failure
1. Auto-brake engages (holds position)
2. Use EDD to descend
3. Check battery connections
4. Resume when fixed

### Entangled Tether
1. Stop winch (press center)
2. Rotate pod (swivel allows 360°)
3. If stuck: use EDD to descend
4. Untangle from ground

## Packing Up

1. **Descend to ground** (remote DOWN)
2. **Disconnect tether** — unclip hook
3. **Unbuckle harness** — all 4 clips
4. **Turn off switches** — SW1, SW2
5. **Disconnect battery** — XT60
6. **Fold frame** — pull pins, fold flat
7. **Wind tether** — back onto winder
8. **Pull ground anchors** — remove stakes
9. **Coil guy lines** — tie neatly
10. **Pack into carry case** — everything fits!
