# PHI TETHER POD — Assembly Guide

**Skill Level:** 12-year-old friendly (with adult supervision)
**Time:** 6-8 hours
**Tools Needed:** Rivet gun, tube cutter, drill, soldering iron, hex keys

---

## Step 1: Cut the Frame Tubes (30 min)

1. Cut aluminum tubing to length:
   - Main frame: 4x 20mm × 400mm (item #7)
   - Secondary: 6x 15mm × 300mm (item #8)

2. File all cut ends smooth:
   - Remove burrs with file
   - Sand edges with 220 grit
   - Safety: sharp aluminum cuts easily!

3. Dry-fit frame:
   - 20mm tubes form outer rectangle
   - 15mm tubes form inner structure
   - Connectors join at corners

---

## Step 2: Assemble the Frame (1 hour)

1. Start with the base rectangle:
   ```
   +----400mm----+
   |             |
   300mm         300mm
   |             |
   +----400mm----+
   ```

2. Connect corners with 4-way connectors (item #10):
   - Push tubes into connector
   - Tighten set screws with hex key

3. Add inner structure:
   - 15mm tubes cross inside rectangle
   - Connect with 3-way connectors (item #9)
   - This supports the seat

4. Add vertical supports:
   - 4x 15mm × 200mm tubes going UP from corners
   - Connect with 3-way connectors
   - This forms the "arms" of the pod

5. **CHECK:** Frame is square (measure diagonals — should be equal)

---

## Step 3: Add Foam Padding (30 min)

1. Cut EVA foam (item #12) to fit seat area:
   - 20mm thick
   - 400mm × 300mm

2. Attach foam to frame:
   - Place foam on seat area
   - Wrap with nylon fabric (item #13)
   - Rivet fabric to frame

3. Add padding to arm supports:
   - Wrap foam around vertical tubes
   - Secure with cable ties

---

## Step 4: Install the Seat (30 min)

1. Place seat pan (item #14) on padded frame:
   - Center it on the frame
   - Mark mounting holes

2. Drill holes and bolt seat:
   - 4x M5 bolts (item #40)
   - Through seat pan into frame
   - Tighten with hex key

3. Attach D-rings (item #17):
   - 4x D-rings at seat corners
   - Bolt through frame
   - These connect to harness

---

## Step 5: Install the Harness (30 min)

1. Thread seat belt (item #15) through D-rings:
   - Over shoulders
   - Across lap
   - Through leg loops

2. Attach quick-release buckles:
   - One at chest (easy reach)
   - Two at lap sides

3. Add memory foam padding (item #16):
   - Wrap around seat belt at shoulder contact points
   - Secure with zip ties

4. Test harness:
   - Sit in pod
   - Buckle all straps
   - Have someone lift pod by tether point
   - Should be secure, not sliding

---

## Step 6: Install the Tether System (30 min)

1. Mount tether winder (item #2) on frame:
   - Position at top center
   - Bolt to frame

2. Thread Dyneema tether (item #1):
   - Start: tie to winder drum
   - Wind 200m onto winder
   - Leave 5m free end

3. Attach quick-release hook (item #3):
   - Clip to free end of tether
   - Test: should clip/unclip easily

4. Install swivel connectors (item #5):
   - One at winder output
   - One at hook input
   - Prevents tether twist

5. Attach carabiners (item #4):
   - Connect hook to swivel
   - Connect swivel to D-ring on frame

6. **TETHER TEST:**
   - Pull tether hard (test strength)
   - Clip/unclip hook
   - Spin swivel — should rotate freely

---

## Step 7: Install the Battery (20 min)

1. Mount battery box (item #19) to frame:
   - Position at bottom (low center of gravity)
   - Secure with bracket + bolts

2. Place Li-Ion battery (item #18) in box:
   - Connect XT60 connector (item #21)
   - Red to +, Black to -

3. Mount battery monitor (item #22):
   - Where you can see it while seated
   - Wire to battery

4. Install fuse:
   - 15A blade fuse near battery positive
   - Protects all circuits

---

## Step 8: Install Electronics (45 min)

1. **Follow the wiring diagram (02_WIRING.md)**

2. Mount winch controller (item #23):
   - On frame, accessible from seat
   - Wire to battery through fuse

3. Install wireless receiver (item #24):
   - Mount inside frame (protected)
   - Antenna pointing up
   - Wire to winch controller

4. Mount height sensor (item #25):
   - Bottom of frame, pointing down
   - Wire to display

5. Install level indicator (item #26):
   - Where pilot can see it
   - Wire to battery

6. Mount LED light (item #27):
   - On frame arm, pointing down
   - Wire to switch

7. Wire toggle switches (item #29):
   - SW1: Winch ON/OFF
   - SW2: Instruments + Light ON/OFF

8. **POWER TEST:**
   - SW1 ON: winch should respond to remote
   - SW2 ON: light + display should work
   - Kill switch: everything stops

---

## Step 9: Anchor System (20 min)

1. Assemble ground anchors (item #30):
   - Screw-type, 1.5kg each
   - 2 anchors for stability

2. Attach anchor rope (item #31):
   - 8mm polypropylene, 30m
   - Tie to anchor
   - Coil and store in pod

3. Prepare guy lines (item #32):
   - 3x 10m lines
   - Attach tensioners
   - Clip to frame D-rings

4. Prepare stakes (item #33):
   - 6x steel Y-stakes
   - Store with anchor

---

## Step 10: Safety Equipment (20 min)

1. Helmet (item #34):
   - Padded, sport style
   - Strap secure

2. Emergency descent device (item #35):
   - 15m cable, auto-brake
   - Mount to frame D-ring
   - Test pull: cable should lock

3. Whistle (item #36):
   - Clip to harness

4. First aid kit (item #37):
   - Store in pod frame

5. Walkie-talkies (item #38):
   - One on pod, one with ground person
   - Pre-set to same channel

6. Emergency light (item #39):
   - Red LED, clip-on
   - Attached to harness

---

## Step 11: Fold Test (15 min)

1. Fold the pod:
   - Remove vertical supports (pull pins)
   - Fold frame flat
   - Wings fold against body

2. Pack into carry case (0.4m):
   - Frame pieces
   - Tether (wound on winder)
   - Battery (in box)
   - Safety gear

3. **PACKED WEIGHT:** 8.2 kg total

4. **DEPLOYMENT TEST:**
   - Unpack from case
   - Extend frame (30 seconds)
   - Connect tether (5 seconds)
   - Ready in 30 seconds

---

## Step 12: Ground Test (20 min)

1. Find a safe location:
   - Open field
   - No overhead wires
   - Flat ground
   - Wind <15 km/h

2. Set up anchors:
   - Drive 2 ground anchors
   - Attach guy lines to pod
   - Run tether through winder

3. Have a friend hold tether while you sit in pod:
   - Buckle harness
   - Turn on SW1
   - Use remote to lift 1m off ground
   - Hold for 30 seconds
   - Lower slowly

4. **CHECK:**
   - [ ] Tether holds your weight
   - [ ] Harness is secure
   - [ ] No frame flex
   - [ ] No strange sounds
   - [ ] Emergency descent works

---

## Pre-Use Checklist

**BEFORE EVERY SUSPENSION:**

- [ ] Anchors driven securely
- [ ] Tether inspected (no fraying)
- [ ] Harness buckled (all clips)
- [ ] Kill switch tested
- [ ] Remote control works
- [ ] Height sensor reads correctly
- [ ] Battery charged (>80%)
- [ ] Emergency descent device accessible
- [ ] Radio works
- [ ] Buddy system (never suspend alone!)
- [ ] Wind speed <20 km/h
- [ ] No overhead wires nearby

## Troubleshooting

| Problem | Cause | Fix |
|---------|-------|-----|
| Winch won't lift | Remote out of range | Move closer |
| Tether twists | Swivel stuck | Lubricate swivel |
| Frame flexes | Bolts loose | Tighten all bolts |
| Can't fold | Pin stuck | Apply penetrating oil |
| Height sensor wrong | Calibration off | Recalibrate |
| Remote doesn't work | Battery dead | Replace remote battery |
| Harness loose | Buckle not clicked | Re-buckle firmly |
| Emergency descent jams | Cable kinked | Inspect + replace |
