# PHI TETHER POD — README

## Quick Start
1. Unpack carry case, deploy tether anchor
2. Extend tether to desired length
3. Power on control unit (hold touch ring 3 sec)
4. Step into pod, secure 5-point harness
5. Rotate touch ring clockwise to ascend
6. Tap ring to lock altitude
7. Rotate counter-clockwise to descend

## Specifications at a Glance
- **MSRP:** $400
- **Battery:** FPB-5 (5 kWh, $400)
- **Weight:** 8.2 kg (total system)
- **Max Load:** 250 kg
- **Max Altitude:** 50m (100m extended)
- **Runtime:** 8 hours
- **Charge Time:** 20 min (phi-harmonic) / 2 hrs (standard)
- **Deploy Time:** 30 seconds

## Safety Warnings
- Always wear the 5-point harness
- Never exceed 250 kg total load
- Do not operate in winds exceeding 40 km/h
- Maintain 30% battery reserve minimum
- Inspect tether before each use
