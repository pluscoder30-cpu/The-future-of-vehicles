## EMERGENCY PROCEDURES

### Emergency Dimensional Return
```
1. Press DIMENSIONAL RETURN button (red, shielded)
2. System locks to D0 (home) frequency
3. Warp field discharges in 2.0 seconds
4. Vehicle returns to home dimension
5. All systems enter safe mode
```

### Passenger Emergency
```
1. Pull EMERGENCY RELEASE handle
2. Door opens manually
3. Exit vehicle immediately
4. Move to 12m safe distance
5. Wait for field discharge
```
