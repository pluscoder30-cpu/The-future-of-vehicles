# PHI FTL CAR — ASSEMBLY GUIDE

## Step-by-Step Build Instructions

---

## PHASE 1: CHASSIS ASSEMBLY (30-50 hours)

### Step 1: Unibody Preparation
```
1. Lay unibody frame on flat surface
2. Verify phi-spaced cross members (618mm)
3. Weld reinforcement points
4. Apply rust-preventive coating
5. Install battery cradle under floor
```

### Step 2: Suspension Mounting
```
1. Install front MacPherson strut towers
2. Install rear multi-link mounting points
3. Mount front coilovers (phi-tuned to 28 N/mm)
4. Mount rear springs (32 N/mm)
5. Install anti-roll bars (φ ratio: 28mm/22mm)
```

### Step 3: Axle & Steering
```
1. Install front steering knuckles
2. Mount rear axle assembly
3. Install differential (phi-ratio: 3.236:1)
4. Connect axle shafts
5. Install power steering rack
6. Verify alignment
```

---

## PHASE 2: FPB-80 BATTERY INSTALLATION (15-25 hours)

### Step 4: Battery Mount
```
1. Install battery cradle under floor pan
2. Secure with 6× M14 bolts (phi-spaced pattern)
3. Verify clearance: 100mm minimum
4. Install thermal insulation mat
5. Route battery cables through frame
```

### Step 5: Battery Connection
```
1. Mount FPB-80 in cradle
2. Connect HV main cables (35mm² orange)
3. Install HV contactor (350A)
4. Connect BMS CAN bus
5. Verify all connections with multimeter
6. DO NOT ENERGIZE until Phase 4 complete
```

---

## PHASE 3: WARP FIELD SYSTEM (25-35 hours)

### Step 6: Warp Coil Installation
```
1. Mount 4 warp coils in phi-square pattern
   ┌───────────────────────┐
   │                       │
   │   C1 ─────── C2      │
   │   │           │      │
   │   │     ●     │      │
   │   │           │      │
   │   C3 ─────── C4      │
   │                       │
   └───────────────────────┘
   
2. Each coil: 432μH, rated 180A peak
3. Connect coil drivers to warp controller
4. Install field emitter nodes (6× around perimeter)
5. Mount resonance stabilizer
```

### Step 7: Dimensional Tuner
```
1. Install 7-band frequency selector
2. Mount dimensional HUD display in dashboard
3. Connect tuner to warp controller
4. Calibrate each dimension frequency
5. Test lock-on to D0 (home dimension)
```

---

## PHASE 4: CABIN & INTERIOR (20-30 hours)

### Step 8: Cabin Assembly
```
1. Install windshield and side windows
2. Mount steering column and wheel
3. Install pedal assembly
4. Mount front sport seats
5. Mount rear bench seat
6. Route all wiring through firewall
```

### Step 9: Dashboard & Controls
```
1. Install custom dashboard
2. Mount 12" touchscreen display
3. Install dimensional navigation controls
4. Wire CAN bus connections
5. Install audio system
6. Test all displays
```

---

## PHASE 5: ELECTRICAL & FINAL (15-25 hours)

### Step 10: Wiring
```
1. Install DC-DC converter
2. Mount auxiliary battery
3. Wire all 12V circuits
4. Install fuse box (10 circuits)
5. Connect CAN bus network
6. Ground all components to chassis
```

### Step 11: Final Assembly
```
1. Install HVAC system
2. Mount exterior mirrors
3. Add body panels
4. Paint and finish
5. Final inspection
```
