# PHI GARBAGE DRONE — ASSEMBLY GUIDE

## Build Instructions

---

## PHASE 1: FRAME (8-10 hours)

1. Print frame parts (20 hours)
2. Assemble arms to center body
3. Install motor mounts

---

## PHASE 2: ROBOTIC ARM (6-8 hours)

1. Print arm linkages
2. Install 3 servos (base, shoulder, gripper)
3. Assemble arm mechanism
4. Test arm movement (0-180°)

---

## PHASE 3: SORTING SYSTEM (4-6 hours)

1. Print 3 collection bins (phi-sized)
2. Install bin door servos
3. Mount bins in center body
4. Test door mechanisms

---

## PHASE 4: SENSORS (3-4 hours)

1. Mount metal detector on arm
2. Mount IR sensors on gripper
3. Mount 1080p camera
4. Connect all to Arduino

---

## PHASE 5: ELECTRONICS (8-10 hours)

1. Wire power system
2. Wire Arduino and sensors
3. Wire frequency generator
4. Wire WiFi and telemetry

---

## PHASE 6: TESTING (4-6 hours)

1. Motor spin test
2. Arm movement test
3. Sorting mechanism test
4. Metal detection test
5. Tethered hover test
