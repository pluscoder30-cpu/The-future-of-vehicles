# PHI_CARGO_CART — Safety Precautions

## CRITICAL SAFETY WARNINGS

> **READ ALL WARNINGS BEFORE OPERATING THE CARGO CART**
> **FAILURE TO FOLLOW SAFETY RULES CAN RESULT IN SERIOUS INJURY OR DEATH**

---

## Electrical Safety

### Battery Hazards
- **LiFePO4 batteries store significant energy** — short circuit can cause fire
- Never expose battery to temperatures above 60°C (140°F)
- Never puncture, crush, or disassemble battery cells
- If battery swells, smells, or smokes — **STOP USE IMMEDIATELY**
- Keep battery enclosure sealed and waterproof
- **Charge only with the supplied 36V LiFePO4 charger**
- Never charge battery near water or in wet conditions
- Unplug charger when fully charged

### High Voltage
- The battery operates at **36V DC** — this can cause burns
- Never touch battery terminals with bare hands
- Always disconnect battery before working on electronics
- Use insulated tools when working near live circuits

### Motor Heat
- Hub motor can reach temperatures up to 65°C under heavy load
- Never touch motor immediately after operation
- Allow 15 minutes cool-down before handling

---

## Load Safety

### Weight Limits
- **Maximum cargo weight: 100 kg (220 lbs)**
- **Maximum total weight: 200 kg (440 lbs)** — cart + cargo
- Exceeding weight limit reduces braking effectiveness and motor life
- Exceeding weight limit can cause frame failure

### Load Distribution
- Distribute cargo evenly in bin
- Keep heavy items low and centered
- Do not stack cargo above bin rim
- Secure loose items to prevent shifting
- Balance left/right weight distribution

### Terrain
- **ONLY use on smooth, flat surfaces** (pavement, concrete)
- Never use on rough terrain, grass, gravel, or steep slopes
- Check surface for cracks, debris, or obstacles before each use
- Reduce speed on uneven surfaces

### Braking
- Test brakes before each use with light load
- Allow extra stopping distance with heavy loads
- Never brake suddenly — progressive braking prevents tipping
- Reduce speed before turns

## Emergency Procedures

### Cart Malfunction
1. **Release throttle immediately**
2. Apply brakes gently
3. If cart is moving, guide it to a stop
4. Turn off power switch
5. Check for issues before continuing

### Battery Emergency
1. If battery smokes or catches fire: **DO NOT USE WATER**
2. Move away from the cart
3. If cargo is flammable, move away from area
4. Use Class D fire extinguisher if available
5. Call emergency services (911)

### Tip-Over
1. If cart tips, let it fall — don't try to catch it
2. Stand clear of falling cargo
3. Assess for injuries before lifting
4. Right the cart carefully
5. Check for damage before continuing

### Load Shift
1. If cargo shifts, stop immediately
2. Secure the cart (brakes on)
3. Reposition cargo
4. Test balance before continuing

## Maintenance Safety

### Before Each Use
- [ ] Check battery voltage (should be >33V)
- [ ] Check all bolts are tight
- [ ] Check motor for damage or loose wires
- [ ] Check brakes function properly
- [ ] Check tires for proper inflation
- [ ] Check remote battery level
- [ ] Test throttle and brake at low speed

### Weekly Maintenance
- [ ] Clean motor with dry cloth
- [ ] Check all wiring connections
- [ ] Test battery balance with multimeter
- [ ] Check wheel bearings for smoothness
- [ ] Tighten all bolts
- [ ] Check tire pressure (35 PSI)

### Monthly Maintenance
- [ ] Full battery charge cycle
- [ ] Check all solder joints for cracks
- [ ] Inspect frame for cracks or damage
- [ ] Check caster swivel operation
- [ ] Lubricate all moving parts
