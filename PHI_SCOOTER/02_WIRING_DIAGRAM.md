## Connector Types

| Connection | Connector | Wire Gauge | Color Code |
|------------|-----------|------------|------------|
| Battery to Controller | XT60 | 12AWG | Red (+), Black (-) |
| Motor Phase A | Bullet 3.5mm | 14AWG | Blue |
| Motor Phase B | Bullet 3.5mm | 14AWG | Green |
| Motor Phase C | Bullet 3.5mm | 14AWG | Yellow |
| Motor Hall Sensors | 5-pin JST | 22AWG | Multi-color |
| Throttle | 3-pin JST | 22AWG | Red, Black, White |
| Brake Cut-off | 2-pin JST | 22AWG | Red, Black |
| LED Display | 5-pin JST | 24AWG | Multi-color |
| Charger | DC Jack 5.5×2.1mm | 16AWG | Center (+), Sleeve (-) |
