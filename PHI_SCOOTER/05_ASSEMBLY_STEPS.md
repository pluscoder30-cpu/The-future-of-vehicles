# PHI_SCOOTER — Assembly Steps

> **Skill Level**: Beginner (12-year-old can do it with adult supervision)
> **Time**: 3-4 hours
> **Tools Needed**: Allen keys, wrenches, screwdrivers, wire strippers, multimeter

---

## Phase 1: Prepare the Scooter (30 minutes)

### Step 1: Inspect the Base Scooter

1. Get a used kick scooter in good condition
2. Check all bolts are tight
3. Check wheels spin freely
4. Check brakes work
5. Check frame has no cracks
6. **Do NOT proceed if scooter needs major repairs**

### Step 2: Remove Front Wheel

1. Flip scooter upside down (rest on handlebars and deck)
2. Release front brake caliper
3. Remove front wheel quick-release or axle nuts
4. Slide wheel out of fork
5. Deflate tire completely
6. Remove tire and tube from rim
7. **Keep all parts organized**

### Step 3: Install Motor in Front Wheel

1. Take the phi-harmonic hub motor (pre-laced in 8.5" rim)
2. Place motor axle in front fork dropouts
3. **IMPORTANT**: Motor axle has flat spots — align with dropout slots
4. Install torque arm on fork:
   - Bolt torque arm to fork leg
   - Ensure arm doesn't rotate with axle
5. Tighten axle nuts to 25 Nm
6. Reinstall tire and tube on motor rim
7. Inflate tire to 40 PSI
8. Reinstall wheel in fork
9. Reconnect brake caliper

---

## Phase 2: Install Battery (30 minutes)

### Step 4: Mount Battery Bracket

1. Position battery bracket on underside of deck
2. Mark 4 mounting holes with pencil
3. Drill 5mm holes at marked positions
4. Bolt bracket to deck using M5 bolts and nuts
5. Add rubber垫片 between bracket and deck (vibration dampening)

### Step 5: Install Battery Pack

1. Slide battery pack into bracket
2. Secure with Velcro straps
3. Add bungee cords for extra security
4. Route battery wire along deck underside
5. Connect XT60 connector to controller wire

---

## Phase 3: Install Electronics (1 hour)

### Step 6: Mount Controller

1. Position controller under deck (in aluminum case)
2. Use 4× M5 bolts to secure to bracket
3. Ensure controller is level (for heat dissipation)
4. Route all wires neatly along deck underside

### Step 7: Install Throttle

1. Remove right grip from handlebar
2. Slide throttle onto handlebar
3. Position for comfortable thumb reach
4. Tighten clamp bolt
5. Route wire along stem to controller
6. Connect to controller throttle input

### Step 8: Install Brake Levers

1. Remove old brake levers
2. Install new e-brake levers (with cut-off switches)
3. Adjust lever position for comfortable reach
4. Connect brake cut-off wires to controller
5. Adjust brake pads to rotor

### Step 9: Install LED Display

1. Mount display bracket on handlebar (center)
2. Position display for easy visibility
3. Tighten clamp
4. Route display wire along stem
5. Connect to controller display port

---

## Phase 4: Wiring (30 minutes)

### Step 10: Connect Motor

1. Route motor cable along fork leg
2. Secure with zip ties every 10cm
3. Connect 3 phase wires (Blue→A, Green→B, Yellow→C)
4. Connect hall sensor connector (5-pin)
5. Double-check all connections

### Step 11: Connect Battery

1. Connect XT60 connector (red→red, black→black)
2. **Do NOT connect yet** — wait until all wiring complete
3. Secure connection with electrical tape

### Step 12: Connect Sensors

1. Connect throttle wire to controller
2. Connect brake cut-off wires to controller
3. Connect LED display wire to controller
4. Route all wires neatly along deck underside
5. Secure with zip ties

### Step 13: Final Wiring Check

1. **Double-check every connection** with multimeter
2. Verify no bare wires touching frame
3. Verify no pinched wires
4. Verify all connectors are fully seated
5. Take a photo of all wiring for future reference

---

## Phase 5: Configuration & Testing (30 minutes)

### Step 14: Power Up

1. **Stand clear of the front wheel**
2. Turn on power switch
3. Verify LED display shows battery level
4. Verify no error codes
5. If error appears, disconnect battery and check wiring

### Step 15: Test Motor (No Load)

1. **Lift front wheel off ground** (use kickstand or prop)
2. Turn on power
3. Gently apply throttle
4. Verify front wheel spins smoothly
5. Verify wheel spins in correct direction (forward)
6. Listen for unusual noises (grinding, clicking)
7. **If anything sounds wrong, STOP and check wiring**

### Step 16: Test Brakes

1. With front wheel spinning, apply brakes
2. Verify motor cuts off immediately
3. Verify wheel stops within 2 meters
4. Test both left and right brake levers

### Step 17: Test Ride

1. **Find a flat, open area with no traffic**
2. Start with Normal speed mode
3. Gently apply throttle and feel motor response
4. Practice starting and stopping
5. Test all 3 speed modes
6. Practice braking at slow speed
7. **Wear full protective gear**

### Step 18: Final Adjustments

1. Adjust brake pad clearance
2. Set speed limit if desired (25 km/h for street legal)
3. **Write down your controller settings**

---

## Troubleshooting

| Problem | Solution |
|---------|----------|
| LED won't turn on | Check battery connection, fuse |
| Motor doesn't spin | Check phase wires, hall sensors |
| Motor spins backward | Swap any 2 phase wires |
| Motor jitters/vibrates | Check hall sensor connector |
| Throttle doesn't work | Check throttle wiring, calibration |
| Brakes don't cut off motor | Check brake lever switches |
| Error code on display | Look up code in controller manual |
