## FIRE DETECTION MISSION

```
PATROL MISSION:
═══════════════════════════════════════════════════════════════

  1. Takeoff with full retardant load
  2. Navigate to patrol area
  3. Fly grid pattern at 30m AGL
  4. Scan with thermal camera
  5. If hot spot detected:
     a. Investigate (approach carefully)
     b. If fire confirmed:
        - Alert fire department
        - If small (< 1m²): apply retardant
        - If large: maintain distance, monitor
  6. Continue patrol
  7. Return to base when battery < 30%

  Coverage: 5000m² per patrol
  Patrol time: 2 hours
```
