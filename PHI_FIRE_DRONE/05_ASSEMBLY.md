# PHI FIRE DRONE — ASSEMBLY GUIDE

## Build Instructions

---

## PHASE 1: FRAME (10-12 hours)

1. Print reinforced frame parts (24 hours)
2. Assemble arms to center body (heavier gauge)
3. Install motor mounts (reinforced)
4. Install prop guards

---

## PHASE 2: MOTORS (4-6 hours)

1. Mount high-power brushless motors
2. Attach large propellers (500mm)
3. Connect 40A ESCs

---

## PHASE 3: RETARDANT SYSTEM (4-6 hours)

1. Mount 2L tank in center body
2. Install high-flow pump
3. Connect tubing to dual nozzles
4. Test spray pattern

---

## PHASE 4: CAMERAS (2-3 hours)

1. Mount MLX90614 thermal sensor
2. Mount 1080p camera
3. Connect to Arduino

---

## PHASE 5: ELECTRONICS (8-10 hours)

1. Wire 24V power system (FPB-10)
2. Wire Arduino and sensors
3. Wire frequency generator
4. Wire dual HC-12 radios

---

## PHASE 6: TESTING (4-6 hours)

1. Motor spin test
2. Retardant spray test (water)
3. Thermal detection test
4. Tethered hover test
