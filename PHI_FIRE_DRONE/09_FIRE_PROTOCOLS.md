# PHI FIRE DRONE — FIRE PROTOCOLS

## Fire Detection and Suppression Guidelines

---

## DETECTION PROTOCOL

| Step | Action |
|------|--------|
| 1 | Patrol grid at 30m AGL |
| 2 | Scan with thermal camera |
| 3 | Monitor for temp > 50°C |
| 4 | Check for smoke sensor trigger |
| 5 | Investigate any anomaly |

---

## SUPPRESSION PROTOCOL

| Step | Action |
|------|--------|
| 1 | Confirm fire (thermal + visual) |
| 2 | Alert fire department |
| 3 | Assess fire size |
| 4 | If < 1m²: position above fire |
| 5 | Activate retardant pump |
| 6 | Apply retardant in sweeping pattern |
| 7 | Monitor for re-ignition |
| 8 | Report to fire department |

---

## RETARDANT APPLICATION

```
RETARDANT DROP PATTERN:
═══════════════════════════════════════════════════════════════

  For small fire (< 1m²):

  1. Hover 5m above fire edge
  2. Apply retardant for 5 seconds
  3. Move to next edge
  4. Apply for 5 seconds
  5. Repeat around fire perimeter
  6. Apply to center for 10 seconds

  Total retardant used: ~1 liter
  Remaining: ~1 liter (for second fire)
```
