## MEDICATION LOADING PROTOCOL

### Step 1: Verify Medication

Before loading any medication:

| Check | Action |
|-------|--------|
| Prescription | Verify licensed physician prescribed |
| Name | Match label to prescription exactly |
| Dosage | Verify correct strength |
| Expiration | Check date — reject if expired |
| Condition | Check for discoloration, particles |
| Storage | Verify proper storage conditions |

## PATIENT ASSESSMENT PROTOCOL

### Vital Signs Monitoring

When drone reaches patient, it automatically:

1. **Measures SpO2** (blood oxygen)
   - Normal: 95-100%
   - Warning: 90-94%
   - Critical: < 90% (alert emergency services)

2. **Measures Heart Rate**
   - Normal adult: 60-100 BPM
   - Warning: < 50 or > 120 BPM
   - Critical: < 40 or > 150 BPM (alert emergency services)

3. **Measures Temperature**
   - Normal: 36.1-37.2°C (97-99°F)
   - Warning: < 35°C or > 38°C
   - Critical: < 33°C or > 40°C (alert emergency services)

4. **Captures ECG** (if pads applied)
   - Rhythm analysis
   - Rate calculation
   - Anomaly detection

## POST-TREATMENT PROTOCOL

### Step 1: Record Treatment

Document in treatment log:
- Date and time
- Patient identifier
- Medications delivered (name, dose)
- Frequency therapy applied (frequencies, duration)
- Vital signs (before and after)
- Patient response
- Any adverse reactions

### Step 2: Monitor Recovery

Continue monitoring for 15 minutes post-treatment:
- Vital signs every 5 minutes
- Patient comfort level
- Any delayed reactions

### Step 3: Return to Base

1. Verify patient stable
2. Transmit treatment data to base
3. Return drone to charging station
4. Recharge battery
5. Restock medication bay
6. Clean and sanitize transducers

## EMERGENCY PROTOCOLS

### If Patient Condition Worsens

```
EMERGENCY RESPONSE:
═══════════════════════════════════════════════════════════════

  1. STOP frequency therapy immediately
  2. ALERT base station (automatic)
  3. CALL emergency services (911)
  4. TRANSMIT patient vitals to emergency services
  5. MAINTAIN drone on scene for first responder guidance
  6. DO NOT attempt advanced medical procedures

  Drone will display:
  ┌──────────────────────────────────────┐
  │  ⚠️ EMERGENCY — CALLING 911 ⚠️      │
  │                                      │

  │  Heart: XX BPM                       │
  │  Temp: XX.X°C                        │

```

### Adverse Reaction Protocol

| Reaction | Action |
|----------|--------|
| Dizziness | Stop therapy, monitor, do not move patient |
| Nausea | Stop therapy, allow recovery, resume if mild |
| Skin irritation | Stop contact therapy, use ambient method |
| Pain increase | Stop therapy, apply cold, seek medical help |
| Allergic reaction | Stop therapy, use medication if available, call 911 |
| Seizure | Stop therapy, protect patient, call 911 |
