## PLANT SELECTION

### Recommended Plants

| Category | Examples | Seed Size | Spacing |
|----------|----------|-----------|---------|
| Leafy greens | Lettuce, spinach, kale | Small | 10cm |
| Herbs | Basil, cilantro, parsley | Small | 15cm |
| Flowers | Marigolds, petunias, zinnias | Small | 15cm |
| Root vegetables | Radishes, carrots | Small | 10cm |
| Legumes | Beans, peas | Medium | 20cm |

### NOT Recommended

| Category | Reason |
|----------|--------|
| Large seeds (corn, squash) | Too heavy for dispenser |
| Trees | Require transplanting |
| Vining plants | Need support structures |
| Invasive species | Environmental risk |

## SOIL PREPARATION

Before planting with drone:

| Step | Action | Details |
|------|--------|---------|
| 1 | Test soil | Check pH, nutrients, moisture |
| 2 | Clear debris | Remove rocks, sticks, weeds |
| 3 | Loosen soil | Till or fork top 10cm |
| 4 | Add compost | If soil is poor quality |
| 5 | Level surface | Smooth for even planting |

| Check | Action |

## WATERING PROTOCOL

### Water Quality

| Parameter | Requirement |
|-----------|-------------|
| pH | 6.0-7.0 |
| Temperature | 15-25°C |
| Source | Clean, potable water |
| Chemicals | No chlorine (let sit 24 hours) |
| Minerals | Low mineral content preferred |

### Watering Schedule

| Plant Stage | Frequency | Amount |
|-------------|-----------|--------|
| Germination | Daily | Light mist |
| Seedling | Every 2 days | 50ml per plant |
| Vegetative | Every 3 days | 100ml per plant |
| Flowering | Every 2 days | 150ml per plant |
| Fruiting | Daily | 200ml per plant |

### Watering Technique

```
WATER APPLICATION:
═══════════════════════════════════════════════════════════════

  1. Descend to 1.5m AGL
  2. Activate water pump
  3. Hover over plant for 3 seconds
  4. Move to next plant
  5. Deactivate pump between plants

  Spray pattern: 30° cone
  Coverage: 1m diameter
  Application rate: 100ml per 10m²

  ┌────────────────────────────────────┐
  │  WATER COVERAGE PATTERN            │
  │                                    │
  │         ╭─────────╮               │
  │       ╱     ●     ╲              │
  │     ╱    plant     ╲             │
  │   ╱                 ╲            │
  │  ╱      1m dia       ╲          │
  │                         │         │
```

## FREQUENCY THERAPY PROTOCOL

### Standard Growth Session

| Step | Frequency | Duration | Purpose |
|------|-----------|----------|---------|
| 1 | 432 Hz | 5 min | Root growth stimulation |
| 2 | 528 Hz | 5 min | Cell division acceleration |
| 3 | 639 Hz | 5 min | Nutrient uptake enhancement |
| **Total** | | **15 min** | Complete growth session |

### Application Method

```
FREQUENCY APPLICATION:
═══════════════════════════════════════════════════════════════

  1. Hover drone 1m above plants
  2. Activate frequency generator
  3. Start with 432Hz (5 minutes)
  4. Switch to 528Hz (5 minutes)
  5. Switch to 639Hz (5 minutes)
  6. Deactivate generator
  7. Move to next area

  Coverage: 2m diameter circle
  Application rate: 15 min per 3m² area
```

## TROUBLESHOOTING

| Problem | Cause | Fix |
|---------|-------|-----|
| Seeds won't drop | Hopper jammed | Clear jam, add agitator |
| Uneven seeding | Wind interference | Fly lower, calibrate dispenser |
| Over-watering | Pump too fast | Reduce flow rate |
| Under-watering | Pump clogged | Clean pump, check tubing |
| Plants wilting | Too much frequency | Reduce duration |
| No germination | Seeds too old | Use fresh seeds |
| Poor growth | Soil quality | Add fertilizer |
| Pest damage | No pest control | Apply organic pest control |

|--------|-------------|-------|
