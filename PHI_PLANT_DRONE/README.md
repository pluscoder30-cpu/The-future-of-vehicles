## QUICK START

### Step 1: Read Everything

Read ALL 16 files in this directory before buying anything.

### Step 2: Order Parts

**Order FPB-5 battery FIRST** (4-6 week lead time).

**Order electronics** (2-4 week shipping): Arduino Mega, MPU6050, sensors, GPS.

**Order all other parts** (1-7 day shipping): Motors, propellers, frame hardware, water pump, seed dispenser parts.

### Step 3: Build

Follow `05_ASSEMBLY.md` in order:
1. Frame assembly (8-10 hours)
2. Motor installation (4-6 hours)
3. Seed dispenser (4-6 hours)
4. Water system (4-6 hours)
5. Electronics wiring (8-10 hours)
6. Frequency generator (4-6 hours)
7. Final assembly (4-6 hours)
8. Testing (4-6 hours)

### Step 4: Test

- Motor spin test (no propellers)
- Hover test (tethered)
- Seed dispenser test (drop test)
- Water spray test (no battery)
- Frequency generator output verification

### Step 5: Deploy

- Load seeds per `09_PLANTING_PROTOCOLS.md`
- Fill water tank
- Set planting area coordinates via WiFi
- Launch and monitor via telemetry
