# PHI WATER DRONE — ASSEMBLY GUIDE

## Build Instructions

---

## PHASE 1: FRAME (8-10 hours)

1. Print frame parts (20 hours)
2. Assemble arms to center body
3. Install motor mounts

---

## PHASE 2: FILTRATION SYSTEM (6-8 hours)

1. Mount water tank (500ml)
2. Install intake filter (mesh)
3. Install carbon filter
4. Install UV LED module
5. Connect pump and tubing
6. Test water flow

---

## PHASE 3: SENSORS (3-4 hours)

1. Mount pH sensor on intake
2. Mount turbidity sensor on output
3. Mount temperature sensor
4. Connect to Arduino

---

## PHASE 4: ELECTRONICS (8-10 hours)

1. Wire power system
2. Wire Arduino and sensors
3. Wire frequency generator
4. Wire WiFi and telemetry

---

## PHASE 5: TESTING (4-6 hours)

1. Motor spin test
2. Filtration flow test
3. Water quality sensor test
4. Frequency generator test
5. Tethered hover test over water
