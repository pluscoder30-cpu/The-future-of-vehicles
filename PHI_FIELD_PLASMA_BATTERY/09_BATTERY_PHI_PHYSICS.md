#### 5.2 Plasma Beta (β)

```

    ┌─────────────────────────────────────────────────────────────┐
    │                                                             │
    │   PLASMA BETA (β) = plasma pressure / magnetic pressure     │
    │                                                             │
    │   β = (n × k × T) / (B² / (2μ₀))                          │
    │                                                             │
    │   Where:                                                    │
    │   ├── n = particle density (m⁻³)                            │
    │   ├── k = Boltzmann constant (1.38 × 10⁻²³ J/K)            │

    │                                                             │

    │                                                             │
    │   CALCULATION:                                              │
    │   β = (10²⁰ × 1.38 × 10⁻²³ × 5000) /                      │
    │       ((0.75)² / (2 × 4π × 10⁻⁷))                          │
    │                                                             │
    │   β = (6.9 × 10⁻¹) / (0.5625 / (2.513 × 10⁻⁶))           │
    │                                                             │
    │   β = 0.69 / (223,700)                                      │
    │                                                             │

    │                                                             │
```
