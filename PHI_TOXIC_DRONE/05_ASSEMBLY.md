# PHI TOXIC DRONE — ASSEMBLY GUIDE

## Build Instructions

---

## PHASE 1: FRAME (10-12 hours)

1. Print reinforced frame parts (24 hours)
2. Assemble arms to center body (heavy duty)
3. Install motor mounts (reinforced)

---

## PHASE 2: SENSORS (4-6 hours)

1. Mount chemical sensor array on bottom
2. Mount pH sensor on intake
3. Mount temperature sensor
4. Connect all to Arduino

---

## PHASE 3: NEUTRALIZER SYSTEM (4-6 hours)

1. Mount 1.5L tank in center body
2. Install 24V pump
3. Connect tubing to nozzle
4. Test spray pattern

---

## PHASE 4: HAZMAT SYSTEM (2-3 hours)

1. Install hazmat buzzer
2. Install red warning LED
3. Apply hazmat labels
4. Test alert system

---

## PHASE 5: ELECTRONICS (8-10 hours)

1. Wire 24V power system (FPB-10)
2. Wire Arduino and sensors
3. Wire frequency generator
4. Wire dual HC-12 radios

---

## PHASE 6: TESTING (4-6 hours)

1. Motor spin test
2. Chemical sensor calibration
3. Neutralizer spray test (water)
4. Hazmat alert test
5. Tethered hover test
