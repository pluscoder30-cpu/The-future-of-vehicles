## 4. Emergency Procedures

### 4.1 Motor Failure
1. AI redistributes thrust
2. If single motor: Continue mission
3. If double motor: Emergency landing
4. If >2 motors: Deploy parachute

### 4.2 Battery Critical
1. Auto-land at nearest safe location
2. Emergency backup battery: 5 min
3. Parachute if above 30m

### 4.3 Communication Loss
1. Auto-return to base
2. Maintain current altitude
3. Follow pre-planned route

### 4.4 Medical Emergency
1. Divert to nearest hospital
2. Increase monitoring frequency
3. Activate cardiac stabilization
