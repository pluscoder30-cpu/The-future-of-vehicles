# PHI AI TOXIC DRONE — ASSEMBLY GUIDE

## Step-by-Step Build Instructions (AI-Enhanced)

---

## PHASE 1: FRAME ASSEMBLY (10-14 hours)

### Step 1: Print Frame Parts

Print all frame components including neutralizer mount and AI bracket.
- Material: PLA 1.75mm
- Infill: 50% gyroid
- Print Time: ~24 hours

### Step 2: Assemble Frame

1. Connect arms to center body
2. Install motor mounts
3. Mount neutralizer tank bracket (chemical-resistant)
4. Mount AI processor bracket

---

## PHASE 2: NEUTRALIZER SYSTEM (4-6 hours)

### Step 3: Install Neutralizer System

```
NEUTRALIZER INSTALLATION:
═══════════════════════════════════════════════════════════════

  1. Mount chemical pump (PTFE-lined)
  2. Install neutralizer tank
  3. Connect PTFE tubing (chemical-resistant)
  4. Mount spray nozzles
  5. Test pump with water first
  6. Check for leaks with test solution
```

---

## PHASE 3: ELECTRONICS (14-18 hours)

### Step 4: Wire Chemical Sensors

Connect MQ-135, MQ-2, pH, TDS, temperature, and color sensors.

### Step 5: Install AI Processor

```
AI PROCESSOR INSTALLATION:
═══════════════════════════════════════════════════════════════

  1. Mount Raspberry Pi Zero 2W
  2. Connect serial to Arduino
  3. Mount camera for spill visual
  4. Flash AI toxin identification model
  5. Test AI with known chemical samples
```

---
