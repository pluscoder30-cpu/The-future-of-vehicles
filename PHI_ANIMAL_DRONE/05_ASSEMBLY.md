# PHI ANIMAL DRONE — ASSEMBLY GUIDE

## Build Instructions

---

## PHASE 1: FRAME (6-8 hours)

1. Print all frame parts (16 hours)
2. Clean and sand parts
3. Assemble arms to center body
4. Install motor mounts
5. Install whisper-quiet prop guards

---

## PHASE 2: MOTORS (3-4 hours)

1. Mount quiet brushless motors
2. Attach whisper-quiet propellers
3. Connect ESCs

---

## PHASE 3: CAMERAS (2-3 hours)

1. Mount 1080p camera on gimbal
2. Mount MLX90614 thermal sensor
3. Connect to Arduino I2C

---

## PHASE 4: FOOD DISPENSER (2-3 hours)

1. Print food hopper
2. Install servo gate
3. Mount on bottom of drone
4. Test dispenser

---

## PHASE 5: ELECTRONICS (6-8 hours)

1. Wire power system
2. Wire Arduino and sensors
3. Wire frequency generator
4. Wire WiFi and telemetry

---

## PHASE 6: FINAL ASSEMBLY (3-4 hours)

1. Install battery
2. Close center body
3. Mount GPS antenna
4. Final inspection

---

## PHASE 7: TESTING (3-4 hours)

1. Motor spin test (no props)
2. Whisper-quiet test (measure dB)
3. Camera test
4. Thermal sensor test
5. Food dispenser test
6. Frequency generator test
7. Tethered hover test
