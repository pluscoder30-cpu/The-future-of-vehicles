# PHI EMOTION CLOAK — README

## Quick Start
1. Unfold cloak and charge battery (20 min phi-harmonic)
2. Put on cloak, fasten phi-lock clasp
3. Download app and pair via Bluetooth
4. Run 5-minute calibration (first use)
5. Wear and let emotions flow
6. Privacy: Press left collar button
7. Social: Press right collar button
8. Wash: Machine wash cold, air dry
